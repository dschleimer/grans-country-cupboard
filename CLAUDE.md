# Gran's Country Cupboard — AI Instructions

## Commands

```bash
# Setup
bundle install && npm install

# Local dev server (localhost:4000)
bundle exec jekyll serve

# Full build (slow first time ~8 min; cached after)
bundle exec jekyll build

# Hybrid mode: use production Cloudflare images, skip local image processing
JEKYLL_ENV=production bundle exec jekyll serve --config _config.yml,_config_prod.yml

# Format recipes before committing (required)
python _tools/format_recipes.py <files>
```

## Architecture

### Collections

Jekyll collections live in underscore-prefix dirs: `_book_recipes/`, `_book_pages/`, `_book_chapters/`, with corresponding index dirs without underscores.

Two collections are generated by plugins — **do not edit manually**:
- `ingredients/` — generated by `_plugins/ingredients.rb`
- `categories/` — generated by `_plugins/categories.rb`

### Plugins (`_plugins/`)

- `ingredients.rb` — extracts ingredient tables, normalizes them, generates ingredient collection pages, rewrites recipe markdown to linkify ingredients
- `categories.rb` — reads `categories:` front-matter, generates category pages
- `book_recipe_sorting.rb` — custom sort order for book recipes
- `jekyll-resize-concurrent.rb` — parallel image resizing (2×CPU threads)

### Image Handling

**Always** render images via `{% include img.html %}`. Never use raw `<img>` tags or markdown `![]()` syntax. For download links, use `{% include asset_link.html %}`.

Image asset taxonomy: `assets/{type}/{id}.jpg`

| Type | ID format |
|------|-----------|
| `original`, `enhanced` | 3-digit zero-padded page number (e.g. `007`) |
| `homepage` | 3-digit zero-padded page number |
| `recipe_crops`, `recipe_photos` | `NNN/recipe_name` |

Common widths: 100px (thumbnails), 395px (half-column), 800px (full-column).

In production, Cloudflare Images handles resizing. In dev, `jekyll-resize-concurrent` does it locally (slow).

### Recipe Front-Matter

```yaml
layout: recipe
page: "007"
recipe: 007/party_meat_balls
page_order: 2
categories:
  - Appetizers
```

### Recipe Markdown Structure

H2 sections in order:
1. **Ingredients** — 3-column table: `Ingredient | Amount | Notes`
2. **Method** — numbered list
3. **Notes From Gran**
4. **Modern Notes**

### Dynamic Content

`functions/forms/recipe_photo.ts` — Cloudflare Pages Function handling photo uploads → GitHub PR creation via Octokit. Static form at `forms/recipe_photo.html`.

### Deployment

GitHub Actions auto-deploys on push to `main`. R2 upload action syncs assets to Cloudflare R2. Manual deploy: `wrangler publish`.

# Applesauce Cake

## Ingredients

| Ingredient  | Amount  | Notes |
| ----------- | ------- | ----- |
| Flour       | 1½ Cups | |
| Sugar       | 1 Cup   | |
| Cocoa       | 3 Tbsp  | |
| Baking Soda | 1 tsp   | |
| Salt        | ½ tsp   | |
| Vinegar     | 1 tsp   | |
| Vanilla     | 1 tsp   | |
| Cooking Oil | 5 Tbsp  | |
| Applesauce  | 1 Cup   | |

## Method

1. Mix flour, sugar, cocoa, baking soda, and salt together in a bowl
1. Make 3 holes in the dry mixture and put vinegar in one, vanilla in one, and cooking oil in one
1. Add 1 cup applesauce and stir well
1. Pour into a greased square pan
1. Bake at 350°F for 45 minutes
1. Serve warm with whipped cream

## Modern Notes

* This is a "wacky cake" or "crazy cake" variation — no eggs or butter needed, making it naturally dairy-free
* The vinegar reacts with the baking soda for leavening
* The "three holes" method was a popular Depression-era technique for mixing wet ingredients into dry without dirtying extra bowls

# Laurie's Apple Cake

## Ingredients

| Ingredient     | Amount | Notes |
| -------------- | ------ | ----- |
| Butter         | ½ lb   | |
| Sugar          | 2 Cups | |
| Flour          | 2 Cups | |
| Baking Soda    | 2 tsp  | |
| Cinnamon       | 1 tsp  | |
| Nutmeg         | ¼ tsp  | |
| Salt           | ⅓ tsp  | |
| Eggs           | 3      | |
| Chopped Apples | 4 Cups | |
| Nuts           | 1 Cup  | |

## Method

1. Cream butter and sugar together
1. Add flour, baking soda, cinnamon, nutmeg, and salt
1. Add eggs and mix well
1. Stir in chopped apples and nuts
1. Bake in a large loaf pan at 350°F for 40 minutes

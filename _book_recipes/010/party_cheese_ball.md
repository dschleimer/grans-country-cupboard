# Party Cheese Ball

## Ingredients

| Ingredient             | Amount | Notes |
| ---------------------- | ------ | ----- |
| Cream Cheese           | 16 Oz  | |
| Shredded Sharp Cheddar | 8 oz   | |
| Roquefort              | 6 Oz   | |
| Minced Onion           | 2 Tbsp | |
| Chopped Pimento                | 1 Tbsp | Optional |
| Chopped Green Pepper           | 1 Tbsp | Optional |
| Worcestershire Sauce   | 2 tsp  | |
| Garlic Salt            | Dash   | |
| Cayenne Pepper         | Dash   | |
| Chopped Nuts           | 1 cup  | Chopped |

## Method
1. Mince onion
1. Chop nuts
1. Chop Pimento and Green Pepper if using
1. Blend Cheese
1. Add Minced Onion, Worcestershire Sauce, Garlic Salt and Cayenne Pepper
1. Add Pimento and Green Pepper if using
1. Blend and shape into a ball
1. Roll into chopped nuts
1. Refrigerate overnight


## Notes From Gran
* Original recipe says "I like to use pecan meal" presumably in place of the chopped nuts.

## Modern Notes
* The original recipe called for two 3 Oz wedges of Roquefort, presumably because this is how it was sold.  However, the recipe calls for blending the cheeses, so I wrote down the total amount rather than the original -- David S

# Oven-Barbequed Chicken

## Ingredients

| Ingredient     | Amount     | Notes |
| -------------- | ---------- | ----- |
| Chicken        | 2          | Cut Up |
| Onions         | 2          | Cut Up |
| Lemon          | 1          | Cut up |
| Seasoned Salt  |            | Lowry's |
| Pepper         |            | |
| Parsely Flakes | Good Pinch | |
| Paprika        |            | |
| Barbeque Sauce |            | |

## Method

1. Preheat oven to 350 °F
1. Cut up chicken, onions and lemon
1. Add remaining ingredients
1. Cover tight
1. Bake for 1 hour
1. Add 1 cup of water if chicken seems to get too dry

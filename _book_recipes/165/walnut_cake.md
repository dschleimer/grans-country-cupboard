# Walnut Cake

## Ingredients

| Ingredient      | Amount         | Notes |
| --------------- | -------------- | ----- |
| Sugar           | 1¼ Cups        | |
| Margarine       | 2 Heaping Tbsp | |
| Eggs            | 3              | Add one at a time |
| Flour           | 2 Cups         | |
| Salt            | ½ tsp          | |
| Baking Powder   | 3 tsp          | |
| Milk            | ¾ Cup          | |
| Vanilla         | 1 tsp          | |
| Chopped Walnuts | ½ Cup          | |

## Method

1. Cream sugar and margarine together
1. Add eggs one at a time, beating after each addition
1. Sift flour, salt, and baking powder together
1. Add dry ingredients alternately with milk
1. Stir in vanilla
1. Fold in chopped walnuts last
1. Pour into a greased and floured loaf pan
1. Bake at 325°F until done

## Modern Notes

* A simple walnut loaf cake — the margarine instead of butter was common in mid-century baking
* You can substitute butter for margarine for richer flavor
* Test for doneness with a toothpick — a loaf pan at 325°F will take about 50–60 minutes

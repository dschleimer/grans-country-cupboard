# California Fried Chicken

## Ingredients

| Ingredient           | Amount     | Notes |
| -------------------- | ---------- | ----- |
| Chicken              | 4 quarters | |
| Sour Cream           | 1 cup      | |
| Lemon Juice          | 2 Tbsp     | |
| Worcestershire Sauce | 2 tsp      | |
| Celery Salt          | 1 tsp      | |
| Garlic               | 2 cloves   | Minced |
| Salt                 | 2 tsp      | |
| Pepper               | 1 tsp      | |
| Paprika              | ½ tsp      | |
| Italian Bread Crumbs |            | |

## Method

1. Preheat oven to 350 °F
1. Mince garlic
1. Mix all ingredients except chicken and bread crumbs
1. Dip chicken in mixture
1. Cover chicken with bread crumbs
1. Grease baking pan and arrange chicken on bottom in single layer
1. Bake, uncovered, 1½ hours or until chicken is tender and surface is crusty brown

## Notes From Gran

* Serves 4

# Everton Taffy

## Ingredients

| Ingredient  | Amount | Notes |
| ----------- | ------ | ----- |
| Brown Sugar | 1 Cup  | |
| Water       | ½ Cup  | |
| Vinegar     | 1 Tbsp | |
| Butter      | ⅛ lb   | |
| Vanilla     | 1 tsp  | |

## Method

1. Boil sugar, water, vinegar, and butter together
1. Cook until it forms a hard ball when a bit is tested in water
1. Add vanilla
1. Pour into a buttered pan
1. When hard, crack into pieces

## Notes From Gran

* Pull candy — buttering fingers to keep from sticking

## Modern Notes

* Everton toffee is a classic English candy from the town of Everton near Liverpool -- Claude (AI)
* Hard ball stage is 250°F–265°F on a candy thermometer -- Claude (AI)
* The vinegar prevents crystallization and adds a slight tang -- Claude (AI)
* Can be pulled while warm for a lighter color and chewier texture, or left to harden for a brittle toffee -- Claude (AI)

# Apple Nut Torte

## Ingredients

| Ingredient     | Amount | Notes |
| -------------- | ------ | ----- |
| Beaten Egg     | 1      | |
| Sugar          | ¾ cup  | |
| Flour          | ½ cup  | |
| Baking powder  | 2 tsp  | |
| Salt           | ½ tsp  | |
| Cinnamon       | ¼ tsp  | |
| Nutmeg         | ⅛ tsp  | |
| Almond extract | ½ tsp  | |
| Chopped Apple  | ½ cup  | |
| Chopped Nuts   | ½ cup  | |

## Method
1. Preheat oven to 325 °F.
2. Grease and flour one pie pan.
3. Mix beaten egg with sugar.
4. Add flour, baking powder, salt, cinnamon, and nutmeg.
5. Add almond extract, apples, and nuts.
6. Mix and spread in pan.
7. Bake for 30 mins.
## Notes From Gran
Cut in pie-shaped wedges and serve with whipped cream or ice cream.

# Apple Nut Torte

## Ingredients

| Ingredient | Amount | Notes |
| ---------- | ------ | ----- |
| Egg            | 1       | beaten  |
| Sugar          | 3/4 cup |         |
| Flour          | 1/2 cup |         |
| Baking powder  | 2 tsp   |         |
| Salt           | 1/2 tsp |         |
| Cinnamon       | 1/4 tsp |         |
| Nutmeg         | 1/8 tsp |         |
| Almond extract | 1/2 tsp |         |
| Apple          | 1/2 cup | chopped |
| Nuts           | 1/2 cup | chopped |

## Method
1. Preheat oven to 325 degrees F.
2. Grease and flour one pie pan.
3. Mix beaten egg with sugar.
4. Add flour, baking powder, salt, cinnamon, and nutmeg.
5. Add almond extract, apples, and nuts.
6. Mix and spread in pan.
7. Bake for 30 mins.
## Notes From Gran
Cut in pie-shaped wedges and serve with whipped cream or ice cream.

# Deviled Scrambled Eggs

## Ingredients

| Ingredient  | Amount  | Notes |
| ----------- | ------- | ----- |
| Eggs        | 6       | Well-beaten |
| Sour Cream  | 1/2 cup | |
| Salt        | 1/2 tsp | |
| Pepper      | 1/4 tsp | |
| Dry Mustard | 1/2 tsp | |
| Butter      | 2 Tbsp  | |

## Method

1. Beat eggs well
1. Combine all ingredients except the butter
1. Heat butter in skillet
1. Pour in egg mixture
1. Cook slowly until set, stirring frequently

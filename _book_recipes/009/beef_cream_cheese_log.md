# Beef Cream Cheese Log

## Ingredients

| Ingredient                | Amount | Notes |
| ------------------------- | ------ | ----- |
| Cream Cheese              | 8 oz   | |
| Mayonnaise                | 1 Tbsp | |
| Worcestershire Sauce      | ½ tsp  | |
| Chopped Ripe Olives       | 2 tbsp | |
| Minced Parsley            | 1 tbsp | |
| Minced Onion              | 1 tbsp | |
| Finely Chopped Dried Beef |        | |

## Method
1. Chop Olives
1. Mince Parsley and Onion
1. Blend Cream Cheese, Mayonnaise and Worcestershire Sauce together
1. Add Chopped Olives, Minced Onion, and Minced Parsley
1. Shape into roll 1.5 inches in diameter
1. Chill until firm
1. While chilling, finely chop Dried Beef
1. Roll log in Chopped Dried Beef

## Notes From Gran
*  Serve with crackers

## Modern Notes
* The original recipe appears to describe the dried beef as "finely snipped" which I interpret as chopped.  My assumption here is that Gran wrote down the recipe as she had it elsewhere.  -- David S

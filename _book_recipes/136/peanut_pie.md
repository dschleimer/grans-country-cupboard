# Peanut Pie

## Ingredients

| Ingredient              | Amount | Notes |
| ----------------------- | ------ | ----- |
| Melted Butter           | ¼ lb   | |
| Sugar                   | 1 Cup  | |
| Coconut                 | ½ Cup  | |
| Raisins                 | ½ Cup  | |
| Chopped Roasted Peanuts | ½ Cup  | |
| Eggs                    | 2      | Slightly beaten |
| White Vinegar           | 2 tsp  | |
| Ground Cloves           | ¼ tsp  | |
| Cinnamon                | ½ tsp  | |
| Chopped Peanuts         | ½ Cup  | For topping |
| Unbaked Pie Shell       | 1      | |

## Method

1. Melt the butter and add the sugar, coconut, raisins, and ½ cup chopped roasted peanuts
1. Add slightly beaten eggs, white vinegar, ground cloves, and cinnamon
1. Mix well and pour into an unbaked pie shell
1. Bake at 350°F for 15 minutes
1. Sprinkle ½ cup chopped peanuts on top
1. Continue baking another 15 minutes

# Hamburger Heaven

## Ingredients

| Ingredient        | Amount  | Notes |
| ----------------- | ------- | ----- |
| Ground Beef       | 1 lb    | |
| Chopped Onion     | 2 large | |
| Butter            | 2 Tbsp  | |
| Tomatoes          | #2 can  | Approximately 2½ cups or 20 ounces |
| Chopped Celery    | ½ cup   | |
| Salt              | 1½ tsp  | |
| Pepper            | ¼ tsp   | |
| Basil             | Pinch   | |
| Broad Egg Noodles | handful | |
| Mushroom soup     | 1 can   | Optional |

## Method

1. Chop onion
1. Brown beef and onion in butter
1. Add tomatoes
1. Chop celery and add
1. Add salt, pepper, and basil
1. Add noodles
1. Optionally add soup
1. Cover
1. Simmer slowly until noodles are tender, stirring occasionally; 30-45 minutes

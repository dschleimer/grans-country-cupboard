# Chicken Turkey or Veal Croquettes

## Ingredients

| Ingredient        | Amount  | Notes |
| ----------------- | ------- | ----- |
| Ground Chicken    | 3 cups  | |
| Thick Cream Sauce | ¾ cups  | |
| Salt              | ½ tsp   | |
| Lemon Juice       | 1 tsp   | |
| Egg               | 2 yolks | separated |
| Celery Salt       | ¼ tsp   | |
| Onion Juice       | ½ tsp   | |
| Bread Crumbs      |         | |

## Method

1. Beat 1 of the egg yolks
1. Mix together all ingredients except Bread crumbs and the second egg yolk
1. Form into cones or balls
1. Beat the second egg yolk with 1 Tbsp water
1. Roll in crumbs
1. Dip in egg mixture
1. Dip in crumbs again
1. Fry in deep fat

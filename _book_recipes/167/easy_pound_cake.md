# Easy Pound Cake

## Ingredients

| Ingredient  | Amount  | Notes |
| ----------- | ------- | ----- |
| Flour       | 2¼ Cups | |
| Sugar       | 1½ Cups | |
| Salt        | ½ tsp   | |
| Baking Soda | ¼ tsp   | |
| Lemon Rind  | 1 tsp   | Grated, optional |
| Vanilla     | 1 tsp   | |
| Butter      | 1 Cup   | Softened |
| Sour Cream  | 1 Cup   | |
| Eggs        | 3       | |

## Method

1. Combine flour, sugar, salt, and baking soda in a mixer bowl
1. Add lemon rind, vanilla, softened butter, and sour cream
1. Add eggs
1. Blend at low speed until combined
1. Beat at medium speed for 3 minutes
1. Pour into a greased and floured 10-inch tube pan
1. Bake at 325°F for 1 hour or until done
1. Cool on a rack for 15 minutes, then remove from pan

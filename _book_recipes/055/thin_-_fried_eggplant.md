# Thin - Fried Eggplant

## Ingredients

| Ingredient            | Amount | Notes |
| --------------------- | ------ | ----- |
| Eggplant              |        | |
| Eggs                  | 2      | |
| Water                 | 1 Tbsp | |
| Seasoned Bread Crumbs |        | |
| Crisco                |        | |

## Method

1. Peel eggplant
1. Slice eggplant very thin
1. Beat eggs, and add 1 Tbsp water
1. Dip each slice of eggplant in egg, then in Seasoned Bread Crumbs
1. Heat Crisco in large skillet
1. Lay eggplant slices flat in pan, filling pan with a single layer
1. Fry to light brown on one side
1. Turn and fry other side of eggplant slices
1. Drain on paper towels
1. Add more Crisco as needed and fry remaining eggplant in batches

## Notes
* Serve warm
* Have catsup available on table for those who want it
* We use this for meatless dinner

# Eggplant Parmesan

## Ingredients

| Ingredient   | Amount     | Notes |
| ------------ | ---------- | ----- |
| Bacon        | 4 strips   | |
| Onion        | 1          | |
| Green Pepper | 1          | |
| Eggplant     | 1          | |
| Tomato Puree | 1 cup      | |
| Cheese       | Few pieces | Recipe specifies "any" cheese |
| Parmesan     | Few dashes | |
| Salt         | To taste   | |
| Pepper       | To taste   | |

## Method

1. Cut up Bacon and fry
1. Brown onion and Green Pepper in bacon fat
1. Peel and cube eggplant
1. Combine and simmer for 2 hours with lid on
1. Add Tomato puree, a few pieces of any cheese and a few dashes of Parmesan
1. Add salt and pepper to taste

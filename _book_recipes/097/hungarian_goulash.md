# Hungarian Goulash

## Ingredients

| Ingredient          | Amount | Notes |
| ------------------- | ------ | ----- |
| Hamburger           | 1 lb   | |
| Tomatoes            | 1 can  | |
| Tomato Puree        | 1 can  | |
| Italian Seasoning   |        | |
| Salt                |        | |
| Pepper              |        | |
| Cut Up Green Pepper | 1      | |
| Cut Up Onion        | 1 med  | |
| Creamettes          | 1 pkg  | This is a brand of pasta - Use Creamettes or Macaroni, not both |
| Macaroni            | ½ pkg  | Use Creamettes or Macaroni, not both |
| Parmesan Cheese     |        | |

## Method

1. Preheat oven to 400 °F
1. Brown Meat
1. Cook pasta until tender
1. Mix all ingredients in baking pan
1. Bake until light brown
1. Reduce to 275 °F
1. Bake 3 hours uncovered, without stirring
1. Add more water to keep it moist

# Boiled Beef Tongue

## Ingredients

| Ingredient         | Amount   | Notes |
| ------------------ | -------- | ----- |
| Smoked Beef Tongue | 1        | |
| Sliced Carrot      | 1        | |
| Sliced Onion       | 1        | |
| Diced Celery       | 2 ribs   | |
| Cut Fine Parsley   | 2 sprigs | |
| Bay Leaf           | ½        | |
| Peppercorns        | ½ tsp    | |
| Cloves             | 2        | |
| Salt               | 2 tsp    | |
| Cabbage            |          | Optional |

## Method

1. Slice carrot and onion
1. Dice Celery
1. Cut Parsley fine
1. Combine all ingredients in a pot
1. Cover and boil for 3 hours

# Roquefort Meat Loaf

## Ingredients

| Ingredient        | Amount  | Notes |
| ----------------- | ------- | ----- |
| Butter            | ¼ cup   | |
| Onion             | 1       | Chopped |
| Garlic            | 1 clove | Chopped |
| Celery            | ½ cup   | Chopped |
| Bread Crumbs      | 2 cups  | Soft |
| Eggs              | 2 + 4   | 2 eggs required - 4 Hard-Boiled eggs optional |
| Roquefort Cheese  | ½ cup   | Crumbled |
| Ground Chuck Beef | 2 lbs   | |
| Salt              | 1 tsp   | |
| Pepper            | ¼ tsp   | |
| Poultry Seasoning | ½ tsp   | |

## Method

1. Pre-heat oven to 325 °F
1. Grease a baking dish well
1. If desired, hard-boil 4 eggs, and set aside to cool
1. Chop onion, garlic, and celery
1. Saute chopped vegetables in butter
1. Remove from heat and add remaining ingredients except hard-boiled eggs
1. If desired, shell hard-boiled eggs and press into meat mixture in a row in center of baking dish
1. Bake for 1 hour

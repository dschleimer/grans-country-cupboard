# Spaghetti Meat Loaf

## Ingredients

| Ingredient   | Amount | Notes |
| ------------ | ------ | ----- |
| Ground Beef  | 1 lb   | |
| Egg          | 1      | Beaten |
| Salt         | 1¼ tsp | |
| Pepper       | ¼ tsp  | |
| Onion        | 4 tbsp | Minced |
| Spaghetti    |        | Recipe calls for leftover spaghetti - with Sauce |
| Butter       |        | For Casserole |
| Sharp Cheese | ½ cup  | Grated |

## Method

1. Preheat oven to 350 °F
1. Butter casserole
1. Combine Remaining ingredients except for cheese
1. Spread in Casserole dish
1. Bake for 1 hour
1. Remove from oven and sprinkle with cheese

## Notes From Gran

* Serves 6

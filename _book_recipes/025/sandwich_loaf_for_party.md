# Sandwich Loaf for Party

## Ingredients

| Ingredient          | Amount | Notes |
| ------------------- | ------ | ----- |
| White Bread         | 1 loaf | Unsliced |
| Butter              |        | |
| Stuffed Olives      |        | |
| Cream Cheese        | 8 oz   | |
| Mayonnaise          |        | |
| Pimento-Nut Filling |        | |
| Curried Egg Filling |        | |
| Deviled Ham Filling |        | |
| Marinated mushrooms |        | Optional - for garnish - sliced |
| Cucumber            |        | Optional - for garnish - crisp green cucumber wheels |
| Other Garnish       |        | Your choice of garnish |

#### Pimento-Nut Filling

| Ingredient   | Amount   | Notes |
| ------------ | -------- | ----- |
| Nuts         | ⅓ cup    | Chopped |
| Pimentos     | 2        | Diced |
| Cream Cheese | 3 oz     | |
| Mayonnaise   | 2 Tbsp   | |
| Salt         | To Taste | |
| Pepper       | To Taste | |

#### Curried Egg Filling

| Ingredient   | Amount | Notes |
| ------------ | ------ | ----- |
| Eggs         | 4      | Hard boiled - Chopped |
| Salt         | ½ tsp  | |
| Pepper       | Dash   | |
| Curry Powder | ½ tsp  | |
| Mayonnaise   |        | To Moisten |

#### Deviled Ham Filling

| Ingredient  | Amount   | Notes |
| ----------- | -------- | ----- |
| Deviled Ham | 1 can    | Recipe calls 4.5 oz but it appears to be sold in 4.25 oz cans |
| Mustard     | To Taste | |
| Pepper      | Dash     | |
| Mayonnaise  |          | To Moisten |

## Method

1. Boil eggs for Curried egg filling
1. Chop eggs
1. Chop nuts
1. Dice pimentos
1. In separate mixing bowls, combine the ingredients for each of the 3 spreads and mix
1. Trim crusts off bread
1. Slice loaf lengthwise into 4 layers
1. Spread each layer with butter
1. spread bottom layer with Pimento-Nut filling
1. Top with second layer of bread
1. Spread Curried Egg filling on second layer of bread
1. Arrange row of stuffed olives down center of second layer
1. Place third layer of bread on top
1. Spread deviled ham on top of third bread layer
1. Top with remaining layer of bread, butter-side down
1. Wrap firmly in foil and chill
1. Unwrap
1. spread with cream cheese, moistened with Mayonnaise
1. Chill until ready to serve
1. Unwrap
1. Garnish
1. Cut with sharp knife

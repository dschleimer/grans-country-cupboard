# Evie's Meat Loaf

## Ingredients

| Ingredient        | Amount  | Notes |
| ----------------- | ------- | ----- |
| Ground Beef       | 2 lb    | |
| Ground Veal       | 1 lb    | |
| Ground Pork       | 1lb     | |
| Catsup            | little  | |
| Eggs              | 2       | |
| Parsley           |         | |
| Salt              |         | |
| Pepper            |         | |
| Italian Seasoning |         | |
| Onion             | 1 large | |
| Celery            | 2 ribs  | |
| Butter            | ⅛ lb    | |
| Croutons          | 2 cups  | |
| Gravy             |         | Recipe calls for France's American Mushroom Gravy |

## Method

1. Preheat oven to 450 °F
1. Mix together the ground meat
1. Add eggs, salt, pepper, and Italian Seasoning
1. Cook onion and celery in butter
1. Boil some water
1. Add Croutons to celery and onions
1. Add enough boiling water to mix together the celery, onions, and croutons
1. Spread vegetables in baking dish
1. Spread meat on top of vegetables
1. Bake at 450 °F for a few minutes
1. Reduce temperature to 250 °F and bake for 2 hours
1. Add gravy just before serving

# Gran's Meat Loaf

## Ingredients

| Ingredient           | Amount        | Notes |
| -------------------- | ------------- | ----- |
| Ground Chuck         | 3 lbs         | |
| Eggs                 | 2             | |
| Mustard              | 1 Tbsp        | |
| Worcestershire Sauce | 1 Tbsp        | |
| Parsley              | 1 Tbsp flakes | |
| Bread                | 2 slices      | Broken up |
| Milk                 | 1 cup         | |
| Onions               | 4             | Cut up |
| Salt                 | To Taste      | |
| Pepper               | To Taste      | |
| Catsup               | ½ cup         | |
| Butter               |               | For casserole |

## Method

1. Preheat oven to 400 °F
1. Butter Casserole
1. Break up bread into milk
1. Cut up onions
1. Mix together all ingredients, except Catsup and butter
1. Place into buttered Casserole
1. Pour Catsup over top
1. Bake for 1 hour

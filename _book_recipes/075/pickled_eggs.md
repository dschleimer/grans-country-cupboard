# Pickled Eggs

## Ingredients

| Ingredient                               | Amount  | Notes |
| ---------------------------------------- | ------- | ----- |
| Water                                    | 4 cups  | |
| Liquid drained from canned pickled beets | 1 cup   | |
| Vinegar                                  | 1 cup   | |
| Sugar                                    | 2 Tbsp  | |
| Pickling Spices                          | 2 tsp   | |
| Salt                                     | 1/2 tsp | |
| Garlic                                   | 1 clove | |
| Bay Leaf                                 | 1       | |
| Eggs                                     | 12      | Hard-Boiled - Shelled |
| Onion                                    | 1 small | Sliced - Separated into rings |

## Method

1. Hard boil eggs, drain, let cool, and remove shells
1. Mix together water, vinegar, and beet liquid
1. Add sugar, pickling spcies, garlic, and bay leaf
1. Mix well
1. Slice onion and separate into rings
1. Add eggs and onion
1. Cover and refrigerate several days

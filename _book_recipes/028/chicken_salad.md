# Chicken Salad

## Ingredients

| Ingredient  | Amount  | Notes |
| ----------- | ------- | ----- |
| Chicken     | 1 Hen   | |
| Egg         | 4 yolks | |
| Salt        | 1 Tbsp  | |
| Butter      | 3 Tbsp  | |
| Dry Mustard | 1 Tbsp  | |
| Vinegar     | ½ Cup   | |
| Milk        | ½ Cup   | |
| Red Pepper  | dash    | |
| Sugar       | 1 Tbsp  | |
| Flour       | 1 Tbsp  | |
| Celery      | 6 ribs  | Cut fine |
| Capers      | 20      | Optional |
| Olives      | 1 dozen | Optional - Ripe - Cut Up |

## Method

1. Cook chicken
1. Slip From bones
1. Cut up Chicken meat
1. Set aside
1. Blend together Salt, Butter, Mustard, Vinegar, Milk, Red Pepper, Sugar, and Flour for dressing
1. Stir and bring to a boil
1. Cut Celery fine
1. Mix together Chicken, Celery, and Dressing 
1. Chill

## Notes From Gran
* Serve on lettuce leaf
* Gran adds capers and olives

## Modern Notes

* This will work just fine with a rotisserie chicken, or other pre-cooked chicken

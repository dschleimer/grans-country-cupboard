# Spiced Peaches or Pears

## Ingredients

| Ingredient        | Amount | Notes |
| ----------------- | ------ | ----- |
| Fruit             | 9 lbs  | Pared and pitted |
| Sugar             | 7 lbs  | |
| Vinegar           | 1 Pint | |
| Powdered Cloves   | 2 Tbsp | |
| Powdered Cinnamon | 2 Tbsp | |
| Allspice          | 1 Tbsp | |
| Whole Cloves      | Few    | For each jar |

## Method

1. Set sugar and vinegar — come to a boil, then pour over fruit and let stand overnight
2. In the morning, add powdered spices and boil slowly until fruit is done and a rich syrup
3. Just before removing from fire, throw away bag of spices and add a whole clove for each jar
4. Seal

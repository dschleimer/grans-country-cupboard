# Chocolate Cream Layer Cake

## Ingredients

| Ingredient     | Amount          | Notes |
| -------------- | --------------- | ----- |
| Cream Cheese   | 8 oz            | Softened |
| Cream          | 3 oz            | |
| Butter         | ½ + ¼ lb        | Divided |
| Powdered Sugar | 1 lb            | |
| Chocolate      | 6 oz            | Semi-Sweet |
| Water          | ¼ cup           | |
| Eggs           | 3               | |
| Flour          | 2¼ cups + extra | |
| Baking Soda    | 1 tsp           | Original recipe calls for just "soda" |
| Salt           | 1 tsp           | |
| Buttermilk     | 1 cup           | |
| Vanilla        | 1 tsp           | |

## Method

1. Soften Cream Cheese + Butter
2. Preheat oven to 350 °F
3. Grease and flour three 9-inch cake pans
4. Beat together cream cheese + ½ lb butter until fluffy
5. Stir in powdered sugar
6. Melt chocolate and stir in
7. Divide into two parts reserving one for frosting
8. Add ¼ cup butter and eggs to the half not reserved for frosting
9. Beat well
10. Combine flour, baking soda, and salt
11. Add to batter, alternating with buttermilk
12. Add vanilla and mix well
13. Spoon batter evenly into pans
14. Bake 35 minutes or until tests done
15. Cool
16. Put layers together with reserved frosting

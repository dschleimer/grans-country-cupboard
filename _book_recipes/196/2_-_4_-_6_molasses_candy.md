# 2-4-6 Molasses Candy

## Ingredients

| Ingredient           | Amount           | Notes |
| -------------------- | ---------------- | ----- |
| Butter               | 2 cups + 1 Tblsp | |
| Raw sugar            | 4 cups           | |
| Unsulphured Molasses | 6 cups           | |
| Water                |                  | |

## Method
1. Cook until it forms a soft ball in water.
2. Butter fingers to keep candy from sticking.
3. Pull candy.

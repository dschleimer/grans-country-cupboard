# Crab Tetrazzini

## Ingredients

| Ingredient  | Amount     | Notes |
| ----------- | ---------- | ----- |
| Crab Meat   | ½ lb       | Fresh, frozen, or canned |
| Shallots    | ½ Tbsp     | Minced |
| Butter      | 2 + 1 Tbsp | |
| Paprika     | ½ tsp      | |
| Flour       | 1 Tbsp     | |
| Light Cream | 1 cup      | |
| Sherry      | 1 Tbsp     | |
| Salt        | To Taste   | |
| Pepper      | To Taste   | |
| Red Pepper  | Dash       | |
| Eggs        | 1 yolk     | slightly beaten |
| Parmesan    | 2 Tbsp     | |
| Rice        |            | Fresh Cooked - Use rice, noodles, or spaghetti |
| Noodles     |            | Use rice, noodles, or spaghetti |
| Spaghetti   |            | Fine - Use rice, noodles, or spaghetti |

## Method

1. Mince Shallots
1. Sauté Crab and shallots in 2 Tbsp butter
1. Stir in Paprika
1. Set aside
1. In separate saucepan, combine 1 Tbsp butter, flour, and light cream
1. Blend and cook
1. Add sherry, salt, pepper, and red pepper
1. Remove from heat, lightly beat the egg yolk and stir it into cream sauce
1. Stir until sauce thickens
1. Combine sauce with crab and pour over rice, noodles or spaghetti
1. Sprinkle with parmesan
1. Brown under broiler

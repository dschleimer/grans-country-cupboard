# Cornmeal Griddle Cakes

## Ingredients

| Ingredient    | Amount  | Notes |
| ------------- | ------- | ----- |
| Cornmeal      | ½ Cup   | |
| Boiling Water | 1½ Cups | |
| Flour         | 2 Cups  | |
| Baking Powder | 5 tsp   | |
| Salt          | 1¼ tsp  | |
| Sugar         | ⅓ Cup   | |
| Milk          | 1¼ Cups | |
| Eggs          | 1       | |
| Melted Butter | 2 Tbsp  | |
| Pecan Meal    | ½ Cup   | |

## Method

1. Add cornmeal to boiling water and boil for 5 minutes, then cool slightly
1. Add remaining dry ingredients — flour, baking powder, salt, and sugar — mixed and sifted, alternately with the milk
1. Add beaten egg, melted butter, and pecans
1. Cook on a hot griddle

## Modern Notes

* These are hearty cornmeal pancakes enriched with pecans
* The boiling water step pre-cooks the cornmeal for a smoother texture
* Pecan meal can be made by pulsing pecans in a food processor until finely ground

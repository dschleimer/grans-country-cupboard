# Pancakes

## Ingredients

| Ingredient    | Amount  | Notes |
| ------------- | ------- | ----- |
| Eggs          | 2       | |
| Milk          | 2½ Cups | |
| Flour         | 2½ Cups | |
| Sugar         | 2 Tbsp  | |
| Shortening    | 4 Tbsp  | |
| Baking Powder | 1 tsp   | |
| Salt          | 1 tsp   | |

## Method

1. Beat eggs and add milk
1. Sift together flour, sugar, baking powder, and salt
1. Add dry ingredients to the egg and milk mixture
1. Add shortening and mix
1. Cook on a hot buttered griddle
1. Serve with syrup and butter

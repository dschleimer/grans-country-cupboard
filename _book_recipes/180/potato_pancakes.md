# Potato Pancakes

## Ingredients

| Ingredient    | Amount  | Notes |
| ------------- | ------- | ----- |
| Potatoes      | 6       | medium raw grated |
| Eggs          | 2       | |
| Baking powder | 1 tsp   | |
| Salt          | 1½ tsp  | |
| Pepper        | ¼ tsp   | |
| Parsley       | 2 Tblsp | fresh minced |
| Flour         | 3 Tbsp  | sifted |
| Onion         | 1       | small grated |

## Method
1. Peel potatoes, then soak in cold water for several hours.
2. Drain and grate potatoes.
3. Beat eggs well.
4. Mix together all ingredients.
5. Drop by spoonfuls onto a hot, greased skillet.
6. Brown on one side, turn, and brown on the other side. 
## Notes From Gran
Good with applesauce, sausage, and cabbage.

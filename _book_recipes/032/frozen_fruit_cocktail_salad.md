# Frozen Fruit Cocktail Salad

## Ingredients

| Ingredient     | Amount   | Notes |
| -------------- | -------- | ----- |
| Cream Cheese   | 16 oz    | |
| Mayonnaise     | 1/2 cup  | |
| Mustard        | 1 Tbsp   | |
| Salt           | 1/4 Tbsp | |
| Fruit Cocktail | 1 can    | Drained - Recipe suggests a can should be 3 1/2 cups |
| Pineapple      | 1 cup    | Diced - Drained |
| Lettuce        |          | Crisp - for serving |

## Method

1. Drain fruit Cocktail well
1. Dice Pineapple if needed and drain well
1. Cream together Cream Cheese, Mayonnaise, Mustard and Salt, beating until smooth
1. Fold in fruit
1. Freeze overnight
1. Cut into squares and arrange on crisp lettuce

## Notes From Gran
* Use as dinner salad or dessert with crackers

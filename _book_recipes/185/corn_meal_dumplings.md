# Corn Meal Dumplings

## Ingredients

| Ingredient     | Amount | Notes |
| -------------- | ------ | ----- |
| Flour          | ¾ Cup  | |
| Corn Meal      | ¼ Cup  | |
| Baking Powder  | ½ tsp  | |
| Salt           |        | |
| Minced Parsley | 1 Tbsp | |
| Egg            | 1      | Beaten |
| Milk           | ½ Cup  | |
| Cooking Oil    | 1 Tbsp | |

## Method

1. Sift flour, corn meal, baking powder, and salt together
1. Add minced parsley, beaten egg, milk, and cooking oil
1. Mix until just blended
1. Drop by spoonfuls into hot cooking liquid — a pot roast or stew
1. Cover tight and let dumplings cook for about 15 minutes
1. Serve alongside the meat

# Gran's Coleslaw

## Ingredients

| Ingredient        | Amount     | Notes |
| ----------------- | ---------- | ----- |
| Cabbage           | 1 head     | Solid head - Grated |
| Celery            | 3 ribs     | With Leaves - Cut Fine |
| Salt              |            | |
| Pepper            |            | |
| Accent            | Few shakes | This is MSG, sold as [Ac'cent](https://accentflavor.com/) today |
| Coleslaw Dressing | 1/2 bottle | Recipe calls for Kraft Dressing |
| Mayonnaise        | 1 cup      | Recipe calls for Blue Ribbon dressing |
| Lemon Juice       | 2 Tbsp     | |
| Sugar             | Pinch      | Optional - if needed |

## Method

1. Grate solid head of cabbage
1. Cut celery fine and add
1. Add Salt and Pepper to taste
1. Add Accent, Coleslaw Dressing, Mayonnaise, and Lemon Juice
1. Taste and add sugar if needed

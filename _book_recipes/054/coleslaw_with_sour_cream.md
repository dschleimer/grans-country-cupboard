# Coleslaw with Sour Cream

## Ingredients

| Ingredient | Amount  | Notes |
| ---------- | ------- | ----- |
| Cabbage    | 1 head  | Finely shredded |
| Sour Cream | 1 cup   | |
| Mayonnaise | 1 Tbsp  | |
| Pepper     | ¼ tsp   | |
| Salt       | ½ tsp   | |
| Sugar      | 2 Tbsp  | |
| Vinegar    | 1½ Tbsp | |

## Method

1. Finely shred cabbage
1. Mix all ingredients well
1. Chill

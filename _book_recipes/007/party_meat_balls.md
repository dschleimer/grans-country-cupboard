# Party Meat Balls

## Ingredients

| Ingredient   | Amount | Notes |
| ------------ | ------ | ----- |
| Milk         | ¼ Cup  | |
| Soft Bread   | ¾ Cup  | |
| Eggs         | 1 Egg  | |
| Sherry       | ¼ Cup  | |
| Grated Onion | 1 Tbsp | |
| Ginger       | ¼ tsp  | |
| Salt         | 1 tsp  | |
| Pepper       | ⅛ ts   | |
| Ground Chuck | 1 lb   | |
| Butter       | 2 Tbsp | For skillet |

## Method
1. Soak Bread in Milk
1. Slightly beat egg
1. Lightly mix remaining ingredients except butter and add to milk & bread
1. Shape into balls 1" in diameter
1. Heat butter in skillet
1. Brown balls evenly 8-10 minutes

## Notes From Gran
* Pre-heat serving dish and plate balls onto hot dish
* Serve plain or with sauce

# Cry Babies

## Ingredients

| Ingredient  | Amount | Notes |
| ----------- | ------ | ----- |
| Sugar       | 1 Cup  | |
| Shortening  | 1 Cup  | |
| Eggs        | 1      | |
| Milk        | ½ Cup  | |
| Baking Soda | 1 tsp  | |
| Nutmeg      | 1 tsp  | |
| Cinnamon    | 2 tsp  | |
| Salt        | ½ tsp  | |
| Molasses    | 1 Cup  | |
| Flour       | 4 Cups | |

## Method

1. Cream sugar and shortening together
1. Add egg and mix well
1. Add milk, baking soda, nutmeg, cinnamon, and salt
1. Add molasses and mix
1. Add flour and mix until combined
1. Drop on a greased sheet
1. Bake at 350°F

## Modern Notes

* Cry babies are old-fashioned soft molasses cookies — the name comes from their crinkly, "crying" appearance when baked
* These are a New England classic, popular in school bake sales
* Drop by spoonfuls — they spread during baking

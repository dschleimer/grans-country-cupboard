# Christmas Cinnamon Snaps

## Ingredients

| Ingredient      | Amount   | Notes |
| --------------- | -------- | ----- |
| Sugar           | 1 Cup    | |
| Butter          | 1 Cup    | |
| Molasses        | ½ Cup    | |
| Dark Corn Syrup | ½ Cup    | |
| Baking Soda     | 2 tsp    | |
| Cinnamon        | 1 Tbsp   | |
| Ginger          | 1 tsp    | |
| Salt            | ½ tsp    | |
| Flour           | 5–6 Cups | If needed |
| Warm Water      | 2 Tbsp   | |

## Method

1. Cream sugar and butter together
1. Add molasses and dark corn syrup, dissolve baking soda in warm water and add
1. Sift 2 cups flour with remaining dry ingredients and add to the mixture
1. Add enough additional flour to make a stiff dough
1. Chill the dough until firm enough to roll out
1. Roll out very thin on a slightly floured board
1. Cut into desired shapes
1. Bake at 350°F–375°F for 8–10 minutes

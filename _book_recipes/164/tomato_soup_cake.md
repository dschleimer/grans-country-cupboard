# Tomato Soup Cake

## Ingredients

| Ingredient          | Amount  | Notes |
| ------------------- | ------- | ----- |
| Butter              | 2 Tbsp  | |
| Sugar               | 1 Cup   | |
| Egg                 | 1       | |
| Baking Soda         | ½ tsp   | |
| Tomato Soup         | 1 Can   | Campbell's |
| Flour               | 1½ Cups | |
| Cinnamon            | 1 tsp   | |
| Cloves              | 1 tsp   | |
| Nutmeg              | 1 tsp   | |
| Raisins             | 1 Cup   | |
| Chopped Nuts        | 1 Cup   | |
| Cream Cheese        | 1       | Small pkg, for icing |
| Butter              | 1 Tbsp  | For icing |
| Confectioners Sugar |         | For icing |

## Method

1. Cream 2 Tbsp butter and sugar together
1. Add egg and beat well
1. Dissolve baking soda in the can of tomato soup
1. Add the soup mixture to the butter, sugar, and egg
1. Add flour, cinnamon, cloves, and nutmeg and mix well
1. Stir in raisins and chopped nuts
1. Bake at 375°F for about 45 minutes
1. For the icing: mix cream cheese and 1 Tbsp butter together
1. Add confectioners sugar until the icing is thick enough to spread
1. Frost the cooled cake

## Modern Notes

* Tomato soup cake was a Depression-era classic — the soup adds moisture, acidity, and a subtle tang without any tomato flavor
* The warm spices completely mask any tomato taste
* This recipe dates to 1922, predating the Depression — it was already a popular frugal recipe
* Use one standard 10.75 oz can of Campbell's condensed tomato soup, undiluted

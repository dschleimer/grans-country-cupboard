# Ham Pinwheels

## Ingredients

| Ingredient       | Amount   | Notes |
| ---------------- | -------- | ----- |
| Roquefort Cheese | ¼ lb     | |
| Cream Cheese     | ¼ cup    | |
| Butter           | ¼ cup    | |
| Ham              | 4 slices | |

## Method

1. Combine Roquefort cheese, cream cheese and butter
1. Spread on ham slices
1. Roll up as jelly roll
1. Wrap in waxed paper
1. Refrigerate
1. When chilled, slice

## Notes From Gran
* Serve one pinwheel on a cracker

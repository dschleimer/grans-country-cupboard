# Deviled Ham + Cheese Spread

## Ingredients

| Ingredient   | Amount | Notes |
| ------------ | ------ | ----- |
| Deviled Ham  | 1 can  | This calls for a 4.25 oz can.  Other recipes call for 4.5 oz can.  In 2025 this is sold in 4.25 oz cans. |
| Cream Cheese | 3 oz   | Cream cheese used to be sold in 3 oz "small" packages alongside the still-extant 8oz packages. |
| Lemon Juice  | ½ tsp  | |
| Horseradish  | ½ tsp  | |

## Method
1. Blend well
1. Serve in a bowl with crackers

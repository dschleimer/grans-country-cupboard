# Jewish Tomato, Cheese + Egg

## Ingredients

| Ingredient | Amount        | Notes |
| ---------- | ------------- | ----- |
| Tomatoes   |               | |
| Salt       |               | |
| Pepper     |               | |
| Butter     |               | |
| Cheese     | 5 or 6 slices | |
| Eggs       | 6             | |

## Method

1. Peel tomatoes if using fresh
1. Cut up tomatoes into fry pan
1. Add salt, pepper, and butter
1. Simmer
1. Add cheese slices
1. Beat up eggs and add on top of tomatoes and cheese
1. Cover and cook slowly until eggs are done

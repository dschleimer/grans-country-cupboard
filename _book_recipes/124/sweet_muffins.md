# Sweet Muffins

## Ingredients

| Ingredient    | Amount | Notes |
| ------------- | ------ | ----- |
| Sugar         | ½ Cup  | |
| Eggs          | 1      | |
| Melted Butter | 2 Tbsp | |
| Sweet Milk    | 1 Cup  | |
| Flour         | 2 Cups | |
| Baking Powder | 2 tsp  | |
| Salt          | ½ tsp  | |

## Method

1. Beat hard and ladle into muffin tins
1. Bake at 400°F for 20–30 minutes

# Baking Powder Cinnamon Buns

## Ingredients

| Ingredient    | Amount | Notes |
| ------------- | ------ | ----- |
| Sifted Flour  | 1 quart | |
| Sugar         | 1/2 Cup  | |
| Egg | 1 | |
| Shortening    | 4 Tbsp | |
| Milk          | 1 Cup  | |
| Baking Powder | 2 tsp  | |
| Salt          | 1/4 tsp  | |
| Butter        | ¼ lb   | For filling |
| Raisins | | For filling |
| Brown Sugar   |        | For filling | 
| Cinnamon | | For sprinkling over top |
| Lard          |        | For greasing pan |

## Method

1. Preheat oven to 425°F
1. Grease baking pan with lard
1. Mix flour, sugar, shortening, milk, baking powder, and salt like biscuit dough
1. Roll out thin and spread with butter
1. Sprinkle generously with brown sugar
1. Roll up and cut into 1½-inch rolls
1. Place cut side down on greased baking pan
1. Sprinkle tops with a little cinnamon
1. Bake 15–20 minutes or until done

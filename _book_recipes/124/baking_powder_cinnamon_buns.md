# Baking Powder Cinnamon Buns

## Ingredients

| Ingredient    | Amount | Notes |
| ------------- | ------ | ----- |
| Flour         | 2 Cups | |
| Sugar         | ¼ Cup  | |
| Shortening    | 4 Tbsp | |
| Milk          | 1 Cup  | |
| Baking Powder | 2 tsp  | |
| Salt          | ½ tsp  | |
| Butter        | ¼ lb   | For filling |
| Brown Sugar   |        | For filling |
| Lard          |        | For greasing pan |

## Method

1. Mix flour, sugar, shortening, milk, baking powder, and salt like biscuit dough
1. Roll out thin and spread with ¼ lb butter
1. Sprinkle generously with brown sugar
1. Roll up and cut into ½-inch slabs
1. Place cut side down in a pan greased with lard
1. Sprinkle tops with a little sugar
1. Bake at 425°F for 15–20 minutes or until done

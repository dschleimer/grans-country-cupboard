# Chocolate Fudge Cake-Layer

## Ingredients

| Ingredient            | Amount    | Notes |
| --------------------- | --------- | ----- |
| Flour                 | 2 Cups    | |
| Baking Powder         | 2 tsp     | |
| Baking Soda           | ½ tsp     | |
| Salt                  | ¼ tsp     | |
| Butter                | ¼ lb      | |
| Sugar                 | 1 Cup     | |
| Egg Yolks             | 2         | Well beaten |
| Chocolate             | 3 squares | Melted |
| Milk                  | 1½ Cups   | |
| Vanilla               | 1 tsp     | |
| Egg Whites            | 2         | Beaten stiff |

## Method

1. Sift together flour, baking powder, baking soda, and salt
1. Cream butter and sugar together
1. Add well-beaten egg yolks
1. Melt the chocolate and add
1. Add the sifted dry ingredients alternately with the milk, beating until smooth after each addition
1. Add vanilla
1. Fold in stiffly beaten egg whites
1. Pour into greased and floured 9-inch layer pans
1. Bake at 325°F until done

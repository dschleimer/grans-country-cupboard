# McGinley Wedding Cold Duck

## Ingredients

| Ingredient   | Amount       | Notes |
| ------------ | ------------ | ----- |
| Punch Bowl   | 1 large      | |
| Ice          | 1 large cake | |
| Champagne    |              | Extra dry |
| Rhine Wine   |              | Finest quality |

## Method
1. Put ice in punch bowl
1. Pour over ice, one bottle in each hand, equal amounts of Champagne and wine
1. Keep punchbowl filled in same proportions
1. Do **<u>NOT</u>** add anything else

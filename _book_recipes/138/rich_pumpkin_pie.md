# Rich Pumpkin Pie

## Ingredients

| Ingredient    | Amount | Notes |
| ------------- | ------ | ----- |
| Pie Shell     | 1      | 9-inch |
| Pumpkin       | 2 Cups | |
| Brown Sugar   | 1 Cup  | |
| Eggs          | 6      | Slightly beaten |
| Cream         | 2 Cups | |
| Salt          | ½ tsp  | |
| Cinnamon      | 1 tsp  | |
| Ground Cloves | ½ tsp  | |
| Mace          | ½ tsp  | Or nutmeg |
| Cognac        | ⅓ Cup  | |

## Method

1. Combine pumpkin, brown sugar, slightly beaten eggs, cream, salt, cinnamon, cloves, and mace
1. Stir in the cognac
1. Pour into a 9-inch pie shell
1. Bake at 375°F for 30–35 minutes or until set

## Notes From Gran

* Serve slightly warm with cheese or whipped cream

## Modern Notes

* This is a truly rich pumpkin pie — 6 eggs and 2 cups cream make for a dense, custard-like filling
* Cognac adds a sophisticated warmth — bourbon or dark rum would also work
* Serving pumpkin pie with cheese (especially sharp cheddar) is a traditional New England practice

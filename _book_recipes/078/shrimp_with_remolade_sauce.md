# Shrimp with Remolade Sauce

## Ingredients

| Ingredient           | Amount     | Notes |
| -------------------- | ---------- | ----- |
| Shrimp               | 3 lbs      | |
| Mayonnaise           | 1 cup      | |
| Eggs                 | 2          | Hard Boiled - Chopped |
| Stuffed Olives       | 6          | Chopped |
| Green Pepper         | 1 Tbsp     | Chopped |
| Garlic Powder        | few dashes | |
| Anchovy Paste        | 1 Tbsp     | Optional |
| Worcestershire Sauce | 1 tsp      | |
| Dry Mustard          | 1 tsp      | |
| Seasoned Salt        |            | |
| Black Pepper         |            | Fresh Ground |

## Method

1. Cook and shell shrimp, if not pre-cooked
1. Chill shrimp for at least 1 hour
1. Hard boil, cool and shell eggs
1. Chop Eggs, Stuffed Olives and Green Pepper
1. Mix well all ingredients except for the shrimp
1. Chill for at elast 1 hour
1. Serve chilled sauce with chilled shrimp

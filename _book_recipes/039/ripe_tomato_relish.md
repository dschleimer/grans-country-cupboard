# Ripe Tomato Relish

## Ingredients

| Ingredient    | Amount  | Notes |
| ------------- | ------- | ----- |
| Tomatoes      | 12      | Ripe |
| Green Peppers | 6       | |
| Onions        | 3 large | |
| Celery        | 3 ribs  | with leaves |
| Vinegar       | 4 cups  | |
| Brown Sugar   | 3 cups  | |
| Salt          | 1 cup   | Not Iodized |
| Black Pepper  | 1 Tbsp  | |
| Celery Seed   | 2 Tbsp  | |
| Mustard Seed  | 2 Tbsp  | |

## Method

1. Put tomatoes, green peppers, onions, and celery through grinder
1. Drain overnight in a bag (like jelly)
1. In morning add remaining ingredients
1. Jar tightly

# Irish Bread

## Ingredients

| Ingredient    | Amount | Notes |
| ------------- | ------ | ----- |
| Flour         | 2 cups | |
| Sugar         | ½ cup  | |
| Eggs          | 2      | |
| Butter        | ¼ lb   | Melted |
| Milk          | ½ cup  | |
| Raisins       | 1 cup  | |
| Baking Powder | 3 tsp  | |
| Salt          | 1 tsp  | |
| Baking Soda   | ½ tsp  | |

## Method

1. Preheat oven to 350 °F
1. Grease Bread Pan
1. Melt butter
1. Add sugar, eggs, and milk
1. Combine Flour, Baking Powder, Baking Soda, Salt, and Raisins
1. Combine wet and dry ingredients
1. Beat until smooth
1. Transfer to bread pan
1. Bake 45 minutes or until done

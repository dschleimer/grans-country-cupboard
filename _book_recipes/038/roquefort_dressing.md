# Roquefort Dressing

## Ingredients

| Ingredient           | Amount   | Notes |
| -------------------- | -------- | ----- |
| Roquefort Cheese     | 1/4 lb   | |
| Blue Cheese          | 1/4 lb   | Optional - may substitute for Roquefort |
| Mayonnaise           | 1/2 pint | |
| Sour Cream           | 1/2 pint | |
| Garlic               | 1 Clove  | May use powdered garlic |
| Worcestershire Sauce | 2 Tbsp   | |
| Lemon                | 1/2      | Juiced |
| Tabasco Sauce        | Dash     | |

## Method

1. Mash cheese
1. Juice half lemon
1. Add other ingredients except Mayonnaise
1. Blend
1. When blended, add Mayonnaise

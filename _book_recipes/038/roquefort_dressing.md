# Roquefort Dressing

## Ingredients

| Ingredient           | Amount  | Notes |
| -------------------- | ------- | ----- |
| Roquefort Cheese     | ¼ lb    | |
| Blue Cheese          | ¼ lb    | Optional - may substitute for Roquefort |
| Mayonnaise           | ½ pint  | |
| Sour Cream           | ½ pint  | |
| Garlic               | 1 Clove | May use powdered garlic |
| Worcestershire Sauce | 2 Tbsp  | |
| Lemon                | ½       | Juiced |
| Tabasco Sauce        | Dash    | |

## Method

1. Mash cheese
1. Juice half lemon
1. Add other ingredients except Mayonnaise
1. Blend
1. When blended, add Mayonnaise

# Shrimp Olive Spread

## Ingredients

| Ingredient             | Amount  | Notes |
| ---------------------- | ------- | ----- |
| Shrimp                 | 1 can   | Recipe calls for a 5 oz can, though it appears to be sold as 6oz cans today |
| Lemon Rind             | 3/4 tsp | Grated |
| Mayonnaise             | 1/4 cup | |
| Pimento Stuffed Olives | 1/4 cup | Chopped |
| Dry Mustard            | 1/8 tsp | |

## Method
1. Combine
1. Mix well
1. Chill

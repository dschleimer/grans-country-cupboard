# Sweetened Whipped Cream Note

## Ingredients

| Ingredient          | Amount | Notes |
| ------------------- | ------ | ----- |
| Heavy Cream         | 1 pint | |
| Confectioners Sugar | 3 Tbsp | |
| Vanilla             | 1 tsp  | |

## Method

1. Whip the heavy cream until stiff
1. Add confectioners sugar and vanilla
1. Refrigerate until used

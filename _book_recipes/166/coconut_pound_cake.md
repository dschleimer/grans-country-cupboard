# Coconut Pound Cake

## Ingredients

| Ingredient          | Amount | Notes |
| ------------------- | ------ | ----- |
| Butter              | ¾ lb   | |
| Sugar               | 3 Cups | |
| Eggs                | 6      | Add one at a time |
| Coconut Milk        | 1 Cup  | |
| Lemon Juice         | 1 Tbsp | |
| Flour               | 3 Cups | |
| Baking Powder       | ¼ tsp  | |
| Salt                | ¼ tsp  | |
| Angel Flake Coconut | 2 Cans | 3½ oz cans |

## Method

1. Cream butter and sugar until light
1. Add eggs one at a time, beating after each addition
1. Sift flour, baking powder, and salt together
1. Add dry ingredients alternately with coconut milk and lemon juice
1. Fold in the coconut
1. Pour into a greased and floured 10-inch tube pan
1. Bake at 350°F for 1 to 1½ hours or until done

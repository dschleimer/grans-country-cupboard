# Ham Croquettes

## Ingredients

| Ingredient   | Amount   | Notes |
| ------------ | -------- | ----- |
| Ground Ham   |          | leftover from baked ham |
| Cream Sauce  |          | Thick |
| Carrot       | some     | Ground |
| Celery       | some     | Ground |
| Mustard      | a little | |
| Bread Crumbs |          | Seasoned |
| Egg          |          | Beaten |
| Milk         | a little | |
| Butter       |          | |

## Method

1. Grind ham, Carrot, and Celery
1. Add a little mustard and enough cream sauce for the mixture to hold together
1. Use a large baking spoon to portion the ham mix
1. Drop each spoonful into seasoned bread crumbs
1. Shape into croquettes
1. Freeze for later use, or continue at once
1. Preheat oven to 350 °F
1. Beat egg and add a little milk
1. Dip croquettes into egg
1. Dip croquettes into breadcrumbs again
1. Put on bakling dish and dot with butter
1. Bake for about 25 minutes until golden brown and hot

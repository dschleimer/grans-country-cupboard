# Sautéd Dove or Quail

## Ingredients

| Ingredient | Amount | Notes |
| ---------- | ------ | ----- |
| Dove Breasts | 24 | |
| Butter | 1 cup or more | |
| White Wine | 1 1/2 cups | Dinner Wine |
| Onion | 1/2 cup chopped | |
| Scallions | 1/2 cup chopped | |
| Celery | 3 Tbsp | Chopped - with leaves |
| Salt | 1/2 tsp | |
| Pepper | 1/2 tsp | |
| Italian Seasoning | 1/2 tsp | |

## Method

1. Chop onions and scallions
1. Chop celery with leaves
1. Saute breasts in butter for 5-7 minutes or until lightly browned
1. Add wine, onion, scallions, celery salt and pepper
1. Cover and simmer 20 minutes
1. Add Italian seasoning and simmer uncovered for 20 minutes more

# Mystery Sandwiches

## Ingredients

| Ingredient      | Amount  | Notes |
| --------------- | ------- | ----- |
| Eggs            | 3       | Hard Boiled |
| American Cheese | ½ lb    | |
| Onion           | 1 small | |
| Pimento         | 1       | |
| Salt            | ½ tsp   | |
| Paprika         | ⅛ tsp   | |
| Mayonnaise      |         | |

## Method

1. Hard boil eggs and allow to cool
1. Combine all ingredients except for Mayonnaise
1. Grind finely
1. Add enough Mayonnaise to m ake it spreadable
1. Refrigerate a couple hours to blend flavors

# Egg and Olive Sandwiches

## Ingredients

| Ingredient             | Amount   | Notes |
| ---------------------- | -------- | ----- |
| Eggs                   | 4        | Hard Boiled - Chopped |
| Pimento Stuffed Olives | ½ cup    | Chopped |
| Celery                 | ½ cup    | Chopped fine |
| Mayonnaise             | ¼ cup    | |
| Chili Sauce            | 1 Tbsp   | |
| Dry Mustard            | ¼ tsp    | |
| Salt                   | To Taste | |
| Pepper                 | To Taste | |

## Method

1. Boil eggs and allow to cool
1. Chop eggs
1. Chop olives
1. Finely chop Celery
1. Mix all ingredients well
1. Spread

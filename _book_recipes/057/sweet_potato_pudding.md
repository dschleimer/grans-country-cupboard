# Sweet Potato Pudding

## Ingredients

| Ingredient              | Amount | Notes |
| ----------------------- | ------ | ----- |
| Raw Sweet Potatoes | 2 cups | Grated |
| Melted Butter           | ¼ cup  | |
| Lemon Juice             | 1 tsp  | |
| Ginger                  | pinch  | |
| Cinnamon                | pinch  | |
| Ground Cloves           | pinch  | |
| Salt                    | ½ tsp  | |
| Brown Sugar             | 1 cup  | |
| Eggs                    | 2      | |
| Pecans                  | ½ cup  | Optional - Pieces or meal |

## Method

1. Preheat oven to 350 °F
1. Grease baking pan
1. Grate Sweet Potatoes
1. Melt butter and add to potatoes
1. Add lemon juice, seasonings, sugar and eggs
1. Blend well
1. Pour into greased baking pan
1. Top with nuts if using
1. Bake for 1 hour

# Sweet Potato Pudding

## Ingredients

| Ingredient     | Amount  | Notes |
| -------------- | ------- | ----- |
| Sweet Potatoes | 2 cups  | Uncooked - Grated |
| Butter         | 1/4 cup | Melted |
| Lemon Juice    | 1 tsp   | |
| Ginger         | pinch   | |
| Ginnamon       | pinch   | |
| Ground Cloves  |         | |
| Salt           | 1/2 tsp | |
| Brown Sugar    | 1 cup   | |
| Eggs           | 2       | |
| Pecans         | 1/2 cup | Optional - Pieces or meal |

## Method

1. Preheat oven to 350F
1. Grease baking pan
1. Grate Sweet Potatoes
1. Melt butter and add to potatoes
1. Add lemon juice, seasonings, sugar and eggs
1. Blend well
1. Pour into greased baking pan
1. Bake for 1 hour

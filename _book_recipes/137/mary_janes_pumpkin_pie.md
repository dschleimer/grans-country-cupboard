# Mary Jane's Pumpkin Pie

## Ingredients

| Ingredient        | Amount  | Notes |
| ----------------- | ------- | ----- |
| Sugar             | 1 Cup   | |
| Flour             | 1 Tbsp  | |
| Salt              | ½ tsp   | |
| Ginger            | ½ tsp   | |
| Cinnamon          | ¾ tsp   | |
| Nutmeg            | ⅛ tsp   | |
| Pumpkin           | 2 Cups  | |
| Molasses          | 1½ Tbsp | |
| Melted Butter     | ½ Tbsp  | |
| Eggs              | 3       | |
| Milk              | 1¾ Cups | |
| Brandy            | 1 Tbsp  | |
| Unbaked Pie Shell | 1       | |

## Method

1. Sift together sugar, flour, salt, ginger, cinnamon, and nutmeg
1. Add pumpkin, molasses, and melted butter
1. Beat eggs with milk and brandy
1. Add to the pumpkin mixture and mix well
1. Pour into an unbaked pie shell
1. Bake at 425°F for 40 minutes or until a knife comes out clean when tested in the center — may take less than 40 minutes

## Notes From Gran

* Serve with whipped cream

## Modern Notes

* This is a richer, spicier pumpkin pie than Gran's version — the molasses and brandy give it a deeper, more complex flavor -- Claude (AI)
* The flour helps set the filling a bit firmer than egg-only custard pies -- Claude (AI)

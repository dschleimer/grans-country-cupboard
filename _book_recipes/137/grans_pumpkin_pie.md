# Gran's Pumpkin Pie

## Ingredients

| Ingredient        | Amount | Notes |
| ----------------- | ------ | ----- |
| Eggs              | 2      | Slightly beaten |
| Sugar             | ½ Cup  | Granulated or brown |
| Salt              | 1 tsp  | |
| Cinnamon          | 1 tsp  | |
| Cloves            |        | Dash |
| Nutmeg            |        | Dash |
| Pumpkin           | 1 Cup  | |
| Melted Butter     | 1 Tbsp | |
| Cream             | 1 Cup  | Or evaporated milk |
| Vanilla           | 1 tsp  | Or 1 Tbsp sherry or 1 Tbsp brandy |
| Unbaked Pie Shell | 1      | |

## Method

1. Mix all ingredients together well
1. Pour into an unbaked pie shell
1. Bake at 400°F for 30 minutes or until a knife comes out clean when tested in the center

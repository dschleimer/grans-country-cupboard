# Fried Rabbit

## Ingredients

| Ingredient | Amount         | Notes |
| ---------- | -------------- | ----- |
| Rabbit     |                | |
| Flour      | 2 Tbsp + extra | |
| Butter     |                | |
| Milk       | 1 pt + extra   | |
| Salt       |                | |
| Pepper     |                | |

## Method

1. Cut up rabbit
1. Wash and dry
1. Dredge in flour, salt and pepper
1. Fry in Butter
1. After all pieces are browned, cover and cook for 1 hour or until rabbit is tender
1. Add water during cooking if needed
1. Remove rabbit from skillet
1. Add 2 tbsp flour
1. Add 1 pint of milk, adding more if needed for desired gravy thickness
1. Stir and cook until thickened
1. Add seasoning to taste
1. Serve with rabbit in gravy

# Molded Bing Cherry Salad

## Ingredients

| Ingredient           | Amount   | Notes |
| -------------------- | -------- | ----- |
| Black Cherry Jello   | 1 lg pkg | |
| Cream Cheese         | 8 oz     | |
| Cream                | a little | |
| Sweet Black Cherries | 1 lg can | |
| Pecans               | 1/2 cup  | Optional - Chopped |

## Method
1. Chop pecans if desired
1. Make jello as directed
1. Let jello set for a little while
1. Beat cream cheese until creamy
1. Add a little cream to make cream cheese smooth
1. After jello has set, whip together jello and cheese
1. Add cherries
1. Add chopped pecans if desired 
1. let set until firm

## Notes From Gran
* Gran uses the juice from cherries in place of cold water \[when making the Jello\], and adds more water to make full amount

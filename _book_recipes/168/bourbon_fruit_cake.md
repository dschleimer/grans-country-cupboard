# Bourbon Fruit Cake

## Ingredients

| Ingredient        | Amount | Notes |
| ----------------- | ------ | ----- |
| Bourbon           | 3 Cups | For soaking fruit |
| Chopped Citron    |        | |
| Candied Cherries  |        | |
| Orange Peel       |        | Candied |
| Lemon Peel        |        | Candied |
| Candied Pineapple |        | |
| White Raisins     |        | |
| Butter            | 2 Cups | |
| Brown Sugar       | 2 Cups | |
| Egg Yolks         | 10     | Add one at a time |
| Flour             | 3 Cups | |
| Pecans            | 2 Cups | |
| Nutmeg            | 1 tsp  | |
| Baking Powder     | 1½ tsp | |
| Egg Whites        | 10     | Beaten stiff |

## Method

1. Pour 3 cups bourbon over the chopped citron, candied cherries, orange and lemon peel, candied pineapple, and white raisins
1. Cover and let stand overnight
1. In the morning, drain the fruit and reserve the bourbon
1. Cream butter and brown sugar well
1. Add egg yolks one at a time, beating after each addition
1. Sift flour, nutmeg, and baking powder together
1. Add dry ingredients alternately with the reserved bourbon
1. Fold in the soaked fruit and pecans
1. Beat egg whites stiff and fold in
1. Oil pans well and line bottoms with brown paper
1. Pour into a 10-inch tube pan or divide among 2–4 small round pans
1. Bake at 275°F — about 4½ hours for the tube pan, 2½ hours for small pans

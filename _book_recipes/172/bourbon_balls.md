# Bourbon Balls

## Ingredients

| Ingredient          | Amount  | Notes |
| ------------------- | ------- | ----- |
| Vanilla Wafers      | 1 Cup   | Crushed |
| Crushed Pecans      | 1 Cup   | |
| Confectioners Sugar | 1 Cup   | |
| Cocoa               | 2 Tbsp  | |
| White Corn Syrup    | 1½ Tbsp | |
| Bourbon             | ¼ Cup   | |
| Confectioners Sugar |         | For rolling |

## Method

1. Mix vanilla wafers, crushed pecans, confectioners sugar, and cocoa together
1. Add white corn syrup and bourbon
1. Mix all ingredients well
1. Roll into 1-inch balls
1. Roll in confectioners sugar

## Modern Notes

* Bourbon balls are a classic no-bake Southern holiday treat
* These improve with age — store in an airtight container for a few days before serving
* The alcohol does not cook off since these are no-bake — they have a real bourbon kick

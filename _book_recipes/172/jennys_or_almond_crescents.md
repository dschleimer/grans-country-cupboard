# Jenny's or Almond Crescents

## Ingredients

| Ingredient          | Amount | Notes |
| ------------------- | ------ | ----- |
| Butter              | 1 lb   | |
| Sugar               | 1 Cup  | |
| Flour               | 4 Cups | |
| Almonds or Pecans   | ¾ lb   | Ground |
| Salt                | 1 tsp  | |
| Vanilla             | 1 tsp  | |
| Confectioners Sugar |        | For rolling |

## Method

1. Mix all ingredients together
1. Form into small crescents on a greased and floured cookie sheet
1. Bake at 400°F for 10–12 minutes
1. Roll in confectioners sugar while warm and again when cool

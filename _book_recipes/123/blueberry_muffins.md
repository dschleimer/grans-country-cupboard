# Blueberry Muffins

## Ingredients

| Ingredient  | Amount | Notes |
| ----------- | ------ | ----- |
| Bisquick    | 2 Cups | |
| Butter      | 2 Tbsp | |
| Egg         | 1      | |
| Milk        | 1 Cup  | |
| Sugar       | ½ Cup  | |
| Blueberries | 1 pint | |

## Method

1. Mix all ingredients together
1. Pour into greased and floured muffin pans
1. Bake at 400°F for 25–30 minutes

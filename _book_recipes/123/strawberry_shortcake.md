# Strawberry Shortcake

## Ingredients

| Ingredient    | Amount | Notes |
| ------------- | ------ | ----- |
| Sifted Flour  | 2 Cups | |
| Salt          | ½ tsp  | |
| Baking Powder | 3 tsp  | |
| Butter        | 1 Cup  | |
| Sugar         |        | |
| Eggs          | 2      | Beaten |
| Milk          | ⅔ Cup  | |
| Strawberries  |        | Fresh |
| Whipped Cream |        | |

## Method

1. Stir together flour, salt, and baking powder
1. Cut in butter
1. Add sugar, beaten eggs, and milk
1. Stir with a fork — makes a stiff batter
1. Pour into 1 large well-greased cake pan
1. Bake at 400°F for 20–30 minutes
1. When done, split the cake in half horizontally and butter the layers
1. Put sugar and strawberries between the layers and on top
1. Serve warm with lots of whipped cream

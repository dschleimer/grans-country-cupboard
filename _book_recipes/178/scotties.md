# Scotties

## Ingredients

| Ingredient   | Amount | Notes |
| ------------ | ------ | ----- |
| Butter       | ¼ lb   | Melted |
| Brown Sugar  | 2 Cups | |
| Flour        | 1 Cup  | |
| Chopped Nuts | 1 Cup  | |
| Eggs         | 2      | |
| Vanilla      | 1 tsp  | |

## Method

1. Melt butter and combine with brown sugar
1. Add flour and chopped nuts
1. Add eggs and vanilla
1. Mix well
1. Pour into a well-greased pan
1. Bake at 325°F for 30–40 minutes
1. When lukewarm, cut into squares

# Ranger Cookies

## Ingredients

| Ingredient       | Amount | Notes |
| ---------------- | ------ | ----- |
| Brown sugar      | 1 cup  | |
| White sugar      | 1 cup  | |
| Butter           | 1 cup  | |
| Eggs             | 2      | |
| Vanilla          | 1 tsp  | |
| Flour            | 2 cups | |
| Baking powder    | 2 tsp  | |
| Baking soda      | ½ tsp  | |
| Salt             | 1 tsp  | |
| Quick oatmeal    | 2 cups | |
| Rice Krispies    | 2 cups | |
| Shredded Coconut | 2 cups | |
| Chopped Walnuts  | 2 cups | |

## Method
1. Preheat oven to 375°F.
2. Grease a cookie sheet.
3. Sift together flour, baking powder, baking soda. and salt. Set aside.
4. Cream both sugars and butter.
5. Add eggs and beat well.
6. Add vanilla.
7. Add flour mixture to creamed mix.
8. Stir in oats, Rice Krispies, coconut, and walnuts.
9. Drop by spoonful onto greased pan.
10. Bake 10 min.
## Notes From Gran
Mix well and in order listed.

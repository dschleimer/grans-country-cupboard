# Cheese Olives

## Ingredients

| Ingredient   | Amount  | Notes |
| ------------ | ------- | ----- |
| Bacon + Cheese | 1 small jar | Best guess is that this refers to commercial cheese spread with bacon in it |
| Butter | 4 tbsp | |
| Tabasco Sauce | | |
| Worcestershire Sauce | | |
| Flour | 3/4 cup | |
| Olives | | |

## Method
1. Preheat oven to 400F
1. Blend together Bacon + Cheese and butter
1. Add a dash of Tabasco Sauce and a dash of Worcestershire Sauce
1. Stir in Flour
1. Form dough
1. Shape about 1 tsp of dough around each olive
1. Place on ungreased baking sheet
1. Bake for 12 - 15 minutes

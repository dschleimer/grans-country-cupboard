# Carrot Cake

## Ingredients

| Ingredient            | Amount  | Notes |
| --------------------- | ------- | ----- |
| Wesson Oil            | 1⅓ Cups | Scant |
| Sugar                 | 2 Cups  | |
| Flour                 | 2 Cups  | Sifted |
| Baking Powder         | 1 tsp   | |
| Baking Soda           | 1 tsp   | |
| Cinnamon              | 1 tsp   | |
| Salt                  | 1 tsp   | |
| Chopped Walnuts       | ½ Cup   | |
| Cooked Grated Carrots | 4 Cups  | |

## Method

1. Put all ingredients in a mixing bowl and beat 2 minutes — do not sift
1. Pour into a greased and floured loaf pan
1. Bake at 350°F for 1½ hours or less
1. Cool and frost with cream cheese frosting
1. Refrigerate

* This version uses cooked (not raw) grated carrots, which gives a smoother, moister cake -- Claude (AI)

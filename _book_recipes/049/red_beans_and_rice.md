# Red Beans and Rice

## Ingredients

| Ingredient           | Amount       | Notes |
| -------------------- | ------------ | ----- |
| Red Beans            | 1 box        | |
| Salt Pork            | ½ lb         | |
| Stewed Tomatoes      | 2 cans       | |
| Worcestershire Sauce | few shakes   | |
| Onions               | 4 medium     | Cut up |
| Green Pepper         | 1            | Cut up |
| Onion Powder         | Big shake    | |
| Garlic Powder        | Little Shake | |
| Bay Leaves           | 2            | Remove Before Serving |
| Parsley              | ½ tsp        | Dried |
| Tabasco Sauce        | Shake        | |
| Maggis               | Shake        | Probably this [seasoning sauce](https://en.wikipedia.org/wiki/Maggi) |
| Seasoned Salt        | Shake        | |
| Seasoned Pepper      | Shake        | |
| Salt                 | To Taste     | |
| Rice                 |              | At serving time

## Method

1. Wash beans well
1. Boil beans 2 minutes with lid on
1. Let beans sit for 1 hour
1. Keep all the water
1. Add Salt Pork, Stewed Tomatoes, and Worcestershire Sauce
1. Cut up onions and green peppers and add to pot
1. Add seasonings
1. Cook slowly on top of stove about 5 hours with lid on
1. Add salt to taste
1. Turn off heat and let cool for 2 hours before serving
1. Cook rice by directions on box

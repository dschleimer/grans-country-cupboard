# Baked Limas

## Ingredients

| Ingredient           | Amount  | Notes |
| -------------------- | ------- | ----- |
| Limas                | 2 cups  | Dried |
| Salt Pork            | ½ lb    | |
| Onion                | 1 large | Chopped |
| Garlic               | 1 clove | Minced |
| Mazola oil           | 2 Tbsp  | |
| Tomato Soup          | 1 can   | |
| Worcestershire Sauce | 2 tsp   | |
| Dry Mustard          | 2 tsp   | |
| Brown Sugar          | ¼ cup   | |
| Vinegar              | ¼ cup   | |
| Salt                 | 1 tsp   | |

## Method

1. Preheat oven to 325 °F
1. Cover Limas and Salt Pork with water
1. Cook until tender
1. Chop Onion
1. Mince Garlic
1. In a separate pan, saute Onion and garlic in Mazola Oil
1. Add Onions and garlic to Limas
1. Add remaining ingredients
1. Put in Casserole dish
1. Bake 25 minutes

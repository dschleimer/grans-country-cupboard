# Deviled Drumsticks

## Ingredients

| Ingredient           | Amount  | Notes |
| -------------------- | ------- | ----- |
| Chicken Legs         | 8       | |
| Red Wine             | 1 cup   | Mellow |
| Wine Vinegar         | 2 Tbsp  | |
| Salt                 | ½ tsp   | |
| Garlic Salt          | ½ tsp   | |
| Pepper               | ¼ tsp   | |
| Brown Sugar          | 2 Tblsp | |
| Worcestershire Sauce | 1 tsp   | |
| Catsup               | ½ cup   | |
| Butter               | 2 Tbsp  | |

## Method

1. Mix well together wine, vinegar, salt, garlic salt, and pepper
1. Pour over chicken
1. Cover
1. Refrigerate overnight
1. Remove chicken and drain, preserving marinade
1. Add brown sugar, Worcestershire Sauce, and catsup to marinade
1. Using a skillet or frying pan, lightly brown the chicken in the butter
1. Pour marinade onto chicken while in the pan
1. Simmer, turnign chicken ofte, util chicken is tender - 40 minutes or more

## Notes From Gran

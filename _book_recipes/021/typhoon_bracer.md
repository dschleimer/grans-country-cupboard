# Typhoon Bracer

## Ingredients

| Ingredient   | Amount            | Notes |
| ------------ | ----------------- | ----- |
| Light Rum    | 3 oz              | |
| Dark Rum     | 3 oz              | |
| Rum          | 1 oz              | Jamaican |
| Orgeat       | 1/2 oz            | |
| Lemon Juice  | 1 oz              | Have additional on hand for adjusting taste |
| Lime         | 1                 | Juiced |
| Fruit Juice  | 3 oz              | Recommended Heart's Delight - Have additional on hand for adjusting taste |
| Papaya Juice | 1 oz              | |
| Grenadine    |                   | For color |
| Drambuie     | 2 tsp per serving | Float as served |

## Method

1. Juice lime
1. In pitcher, combine Rums, Orgeat, 1/2 oz Lemon Juice, Lime Juice, Fruite Juice, and Papaya Juice
1. Mix together
1. Add grenadine to tint pink to preferred shade
1. Taste and add:
  * Additional Lemon juice if too sweet
  * additional Fruit juice if too sour
1. Pour over tall glass of chopped ice
1. Float 2 tsps Drambuie on top of each glass as served

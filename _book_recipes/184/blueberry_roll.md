# Blueberry Roll

## Ingredients

| Ingredient | Amount | Notes |
| ---------- | ------ | ----- |
| Flour                | 2 cups                      | |
| Salt                 | 1 tsp                       | |
| Granulated sugar     | 1 Tblsp + 3/4 cup           | |
| Baking powder        | 4 tsp                       | |
| Butter               | 3 Tblsp + 2 Tblsp + 1/4 cup | |
| Milk                 | 3/4 cup                     | |
| Blueberries          | 2 cups                      | |
| Confectioner's sugar | 3/4 cup                     | sifted |
| Orange juice         | 2 Tblsp                     | |

## Method
1. Preheat oven to 375°F.
2. Grease a rectangular baking pan.
3. Sift together flour, salt, baking powder, and 1 Tblsp gran. sugar.
4. Work in with fingers 3 Tblsp butter.
5. Add milk to mixture and form dough.
6. Mix blueberries with 3/4 cup gran. sugar.
7. Turn dough onto floured board and roll to an oblong shape 1/2" thick.
8. Spread blueberry mixture over dough.
9. Dot with 2 Tblsp butter.
10. Roll up like a jelly roll.
11. Pinch ends tight.
12. Lay roll in greased pan.
13. Bake 35 min or until done.
14. Make hard sauce by creaming 1/4 cup butter, confectioner's sugar, and orange juice.
## Notes From Gran
Whipped cream is also very good.

# Jelly Roll

## Ingredients

| Ingredient          | Amount | Notes |
| ------------------- | ------ | ----- |
| Eggs                | 3      | |
| Sugar               | 1 Cup  | |
| Water               | 5 Tbsp | |
| Flour               | 1 Cup  | |
| Salt                | ½ tsp  | |
| Baking Powder       | ½ tsp  | |
| Vanilla             | 1 tsp  | |
| Jelly               |        | To taste |
| Confectioners Sugar |        | For dusting |

## Method

1. Beat eggs until very light
1. Add sugar and water, beat again
1. Add dry ingredients — flour, salt, and baking powder — then vanilla
1. Pour into a greased 10×15-inch pan, lined with butter or wax paper
1. Bake at 325°F for a few minutes — watch carefully, it is done when lightly browned
1. Turn out onto a clean cloth sprinkled with confectioners sugar
1. Spread with jelly and roll up
1. This recipe dates to 1929

## Modern Notes

* The key to a good jelly roll is not overbaking — the cake must be flexible enough to roll without cracking
* Roll while still warm — it becomes brittle as it cools
* Use any flavor of jelly or jam you prefer

# Swedish Meat Balls

## Ingredients

| Ingredient           | Amount | Notes |
| -------------------- | ------ | ----- |
| Ground Beef          | 1 lb   | |
| Pork Sausage         | ½ lb   | |
| Bread Crumbs         | 1 cup  | Soft |
| Light Cream          | 1 cup  | |
| Nutmeg               | ¼ tsp  | |
| Salt                 | 1 tsp  | |
| Pepper               | ¼ tsp  | |
| Sugar                | 1 tsp  | |
| Parsley              | 2 Tbsp | Chopped |
| Instant Minced Onion | 2 Tbsp | |
| Butter               | 2 Tbsp | |

## Method

1. Chop parsley
1. Mince onion if using fresh
1. Combine all ingredients except butter
1. Beat vigorously with fork until blended and light
1. Gently shape into 1-inch balls
1. Brown in butter over medium heat
1. Turn heat down to low and cook through - 15 minutes

## Notes From Gran

* Makes 4 dozen balls
* Serve warm

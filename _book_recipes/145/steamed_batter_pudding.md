# Steamed Batter Pudding

## Ingredients

| Ingredient      | Amount | Notes |
| --------------- | ------ | ----- |
| Eggs            | 2      | Well beaten |
| Sugar           | 4 Tbsp | |
| Melted Butter   | 4 Tbsp | |
| Sweet Milk      | 1 Cup  | |
| Flour           | 2 Cups | |
| Chopped Raisins |        | |
| Baking Powder   | 3 tsp  | |

## Method

1. Beat eggs well with sugar
1. Add melted butter
1. Add sweet milk
1. Stir in flour and baking powder
1. Add chopped raisins
1. Steam for ½ hour in greased cups or in a covered pan
1. Serve with hard sauce or maple syrup

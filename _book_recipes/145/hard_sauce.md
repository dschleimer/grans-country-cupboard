# Hard Sauce

## Ingredients

| Ingredient    | Amount | Notes |
| ------------- | ------ | ----- |
| Sugar         | 1 Cup  | |
| Egg           | 1      | |
| Flour         | 1 Tbsp | |
| Butter        | ⅛ lb   | |
| Salt          | ⅛ tsp  | For consistency |
| Boiling Water |        | Add for desired consistency |
| Vanilla       | 1 Tbsp | |

## Method

1. Mix sugar, flour, and salt together
1. Add butter and mix
1. Set over a hot stove to liquefy
1. Add boiling water for desired consistency
1. Add vanilla

# White Fruit Cake

## Ingredients

| Ingredient          | Amount | Notes |
| ------------------- | ------ | ----- |
| Sifted Flour        | 4 Cups | |
| Baking Powder       | 1 tsp  | |
| Baking Soda         | ½ tsp  | |
| Salt                | ½ tsp  | |
| Candied Orange Peel | ½ lb   | |
| Candied Lemon Peel  | ½ lb   | |
| Candied Pineapple   | ½ lb   | |
| Red Cherries        | ½ lb   | Candied |
| Citron              | ½ lb   | |
| White Raisins       | 1 Box  | |
| Blanched Almonds    | 1 lb   | Finely chopped |
| Butter              | 1 Cup  | |
| Lemon Juice         | 1 Tbsp | |
| Eggs                | 10     | Separated |

## Method

1. Cut all fruit finely
1. Sift dry ingredients 3 times
1. Sift ⅓ cup of the flour over the fruit and nuts, mix well
1. Cream butter and sugar well
1. Add remaining flour mixture slowly
1. Add lemon juice, fruit, and nuts
1. Beat egg whites stiff and fold in
1. Pour into a greased and floured tube pan or bread pans
1. Bake at 250°F for 2–2½ hours, then increase to 300°F for 15 minutes
1. Makes 6 lbs

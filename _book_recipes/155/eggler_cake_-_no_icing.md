# Eggler Cake - No Icing

## Ingredients

| Ingredient    | Amount  | Notes |
| ------------- | ------- | ----- |
| Butter        | ¾ Cup   | |
| Sugar         | 1½ Cups | |
| Eggs          | 3       | One at a time |
| Flour         | 2½ Cups | |
| Baking Powder | 2 tsp   | |
| Cinnamon      | ½ tsp   | |
| Cloves        | ¼ tsp   | |
| Nutmeg        | 1 tsp   | |
| White Raisins | 1 Cup   | |
| Milk          | 1 Cup   | |

## Method

1. Cream butter and sugar together
1. Add 3 eggs, one at a time
1. Sift flour, baking powder, cinnamon, cloves, and nutmeg together
1. Add dry ingredients alternately with milk
1. Stir in white raisins
1. Pour into a greased and floured tube or loaf pan
1. Bake at 325°F for about 1 hour or done

## Notes From Gran

* Grand-dad Marter's favorite cake

## Modern Notes

* This is a spiced raisin cake that needs no icing — the spices and raisins provide all the flavor -- Claude (AI)
* White raisins (golden raisins/sultanas) are milder and sweeter than dark raisins -- Claude (AI)

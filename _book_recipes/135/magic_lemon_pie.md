# Magic Lemon Pie

## Ingredients

| Ingredient               | Amount | Notes |
| ------------------------ | ------ | ----- |
| Sweetened Condensed Milk | 1⅓ Cup | |
| Egg Yolks                | 2      | |
| Lemon Juice              | ½ Cup  | |
| Sugar                    | 2 Tbsp | |
| Lemon Peel               | 2 Tbsp | Grated |
| Baked Pie Shell          | 1      | |
| Sweetened Whipped Cream  | ⅓ Cup  | Or meringue |

## Method

1. Mix sweetened condensed milk, egg yolks, lemon juice, sugar, and grated lemon peel together
1. Stir well — the mixture will thicken on its own
1. Pour into a baked pie shell
1. Top with sweetened whipped cream or meringue
1. If using meringue, beat egg whites stiff and gradually add ¼ cup sugar, then brown in a 330°F oven

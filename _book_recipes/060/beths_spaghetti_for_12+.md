# Beth's Spaghetti for 12+

## Ingredients

| Ingredient           | Amount       | Notes |
| -------------------- | ------------ | ----- |
| Ground Chuck         | 3 lbs        | |
| Onions               | 8 large      | Cut up fine |
| Celery               | 3 ribs       | Cut up fine |
| Green Pepper         | 1            | Cut up fine |
| Mushrooms            | 1 large can  | Recipe calls for stems and pieces |
| Tomatoes             | 2 large cans | |
| Ragu Sauce           | 32 Oz        | Recipe calls for 2 large jars and then specifies 32 Oz, presumably fluid ounces |
| Salt                 | To Taste     | |
| Pepper               | To Taste     | |
| Italian Seasoning    | To Taste     | |
| Garlic Powder        | To Taste     | |
| Worcestershire Sauce | To Taste     | |
| Parmesan             | 2 Tbsp       | For serving |
| Cooking Oil          |              | |
| Spaghetti            |              | |

## Method

1. Finely cut up Onions, Celery, and Green Pepper
1. Add mushrooms
1. Saute in cooking oil in large pan
1. Add meat and brown
1. Add tomatoes and Ragu
1. Rinse Ragu jars each with 1 cup of water and add water to pan
1. Add seasoning mix
1. Bring to a slow boil
1. Simmer 3 or more hours
1. Cook spaghetti according to box
1. Serve with Sauce and Parmesan

# 15 Crab Cakes

## Ingredients

| Ingredient   | Amount   | Notes |
| ------------ | -------- | ----- |
| Crab meat    | 1 lb.    | carefully picked free of all shell |
| Butter       | 1/4 lb.  | |
| Flour        | 3 Tbsp.  | |
| Milk         | 2 cups   | |
| Nutmeg       | 1 dash   | |
| Red Pepper   | 1 dash   | |
| Parsley      | 1 dash   | chopped fine |
| Salt         | to taste | |
| Bread crumbs |          | |
| Crisco       |          | all-vegetable shortening |

## Method
1. Cook butter, flour, and milk in a pot until very thick, stirring constantly.
2. Add nutmeg, pepper, parsley, and salt.
3. Stir in crab last.
4. Cool.
5. Take mixture by tablespoonfuls and drop into bread crumbs.
6. Mold into 15 cakes.
7. Allow to set several hours in refrigerator.
8. Fry in Crisco oil without further dipping in crumbs.

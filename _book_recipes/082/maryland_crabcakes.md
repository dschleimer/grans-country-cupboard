# Maryland Crabcakes

## Ingredients

| Ingredient           | Amount | Notes |
| -------------------- | ------ | ----- |
| Fresh Crab Meat      | 3 cups | |
| Salt                 | ½ tsp  | |
| Pepper               | ½ tsp  | |
| Beaten Eggs          | 2 + 2  | See modern notes |
| Finely Chopped Onion | ⅓ cup  | |
| Dry Mustard          | ½ tsp  | |
| Mayonnaise           | 3 Tbsp | |
| Flour                |        | |
| Bread Crumbs         |        | Fine Dry Bread Crumbs |

## Method

1. Mix well
1. Shape into cakes
1. Roll cakes in flour
1. Dip cakes into beaten eggs, then Bread Crumbs
1. Fry in hot fat
1. Drain on paper

# Fried Oysters

## Ingredients

| Ingredient   | Amount | Notes |
| ------------ | ------ | ----- |
| Oysters      |        | |
| Saltines     |        | aka Saltine Crackers |
| Bread Crumbs |        | |
| Egg          | 1      | |
| Milk         | 1 Tbsp | |
| Salt         |        | |
| Pepper       |        | |
| Flour        |        | |

## Method

1. Crumble Saltines and mix with equal amount of Bread Crumbs 
1. Beat egg with milk
1. Shuck oysters
1. Roll oyster in crumbs
1. Dip in egg
1. Salt and pepper
1. Roll in flour
1. Fry in shallow pan in hot oil, turning only once
1. Drain on paper

# Crab Delaware

## Ingredients

| Ingredient   | Amount  | Notes |
| ------------ | ------- | ----- |
| Crab meat            | 1 lb.   |        |
| Egg                  | 1 lb.   | beaten |
| Worcestershire sauce | 1 tsp.  |        |
| Dry mustard          | 1 tsp.  |        |
| Mayonnaise           | 1 cup   |        |
| Bread crumbs         |         |        |
| Butter               |         |        |

## Method
1. Preheat oven to 350 degrees.
2. Mix all ingredients except bread crumbs and butter.
3. Put into glass baking dish.
4. Sprinkle bread crumbs on top.
5. Dot with butter.
6. Bake for 1/2 hour.
7. Serve with sherry.

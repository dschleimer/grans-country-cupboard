# Shrimp Newburg

## Ingredients

| Ingredient           | Amount     | Notes |
| -------------------- | ---------- | ----- |
| Shrimp               | 1½ lbs     | Cooked |
| Butter               | 3 Tbsp     | |
| Flour                | 2½ Tbsp    | |
| Milk                 | 1½ cups    | Use Milk or Cream not both |
| Cream                | 1½ cups    | Use Milk or Cream not both |
| Catsup               | 4 Tbsp     | |
| Chili Sauce          | 2 Tbsp     | |
| Worcestershire Sauce | ¾ Tbsp     | |
| Lemon Juice          | little     | |
| Salt                 | Pinch      | |
| Paprika              | Dash       | |
| Sherry               | 2 + 1 Tbsp | |
| Patty Shells         |            | For serving |
| Rice                 |            | For serving |

## Method

1. Cook shrimp if not pre-cooked
1. Melt Butter and blend in Flour
1. Stir in milk or cream
1. Cook until thick
1. Stir in Catsup, Chili Sauce, Worcestershire Sauce, and Lemon Juice
1. Add shrimp
1. Heat
1. Add salt, Paprika and 2 Tbsp Sherry
1. Just before serving, add 1 more Tbsp sherry
1. Serve on patty shells or rice

# Strawberry Jello

## Ingredients

| Ingredient          | Amount      | Notes |
| ------------------- | ----------- | ----- |
| Strawberry Jello    | 2 pkgs      | |
| Boiling Water       | 2 Cups      | |
| Crushed Pineapple   | 1 small can | |
| Frozen Strawberries | 1 pkg       | |
| Sour Cream          | 1 pint      | |

## Method

1. Dissolve 2 packages strawberry Jello in 2 cups boiling water
1. Add crushed pineapple and frozen strawberries, mashing and mixing
1. Divide the mixture in half
1. Pour the first half into a mold or dish and let it set
1. Spread 1 pint sour cream on the set layer
1. Pour the remaining half of the Jello mixture on top
1. Chill until fully set

## Notes From Gran

* Good with or without whipped cream

## Modern Notes

* This is a layered Jello salad with a sour cream middle — a classic mid-century party dish
* The frozen strawberries help the Jello set faster while adding fruit

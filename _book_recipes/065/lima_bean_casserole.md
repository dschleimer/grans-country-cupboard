# Lima Bean Casserole

## Ingredients

| Ingredient             | Amount | Notes |
| ---------------------- | ------ | ----- |
| Limas                  | 10 oz  | Recipe calls for 1 package of frozen limas |
| Chopped Onions         | 2 Tbsp | |
| Grated Sharp Cheddar   | ½ cup  | |
| Salt                   | ½ tsp  | |
| Pepper                 | ⅛ tsp  | |
| Cream of Mushroom Soup | 1 can  | |
| Milk                   | ½ cup  | |
| Butter                 |        | |

## Method

1. Preheat oven to 350 °F
1. Butter Casserole Dish
1. Chop Onions
1. Mix together Limas, Onions, Cheese, Salt, Pepper, and Soup
1. Rinse soup can with ½ cup milk and add to mixture
1. Bake 35 to 45 minutes

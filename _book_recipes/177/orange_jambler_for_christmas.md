# Orange Jambler for Christmas

## Ingredients

| Ingredient         | Amount | Notes |
| ------------------ | ------ | ----- |
| Sugar              | 1 Cup  | |
| Butter             | 1 Cup  | |
| Eggs               | 3      | |
| Flour              | 4 Cups | |
| Baking Powder      | 1 tsp  | |
| Milk               | 5 Tbsp | |
| Grated Orange Rind |        | |

## Method

1. Cream sugar and butter together
1. Add eggs and mix well
1. Add flour and baking powder
1. Add milk and grated orange rind
1. Mix well, then drop on a greased pan
1. Bake at 400°F for 6–8 minutes

## Modern Notes

* A "jambler" is an old-fashioned term for a small, round cookie — also spelled "jumble" or "jumbal" -- Claude (AI)
* These are simple orange-flavored drop cookies, traditional for Christmas -- Claude (AI)
* Don't overbake — they should be just barely golden -- Claude (AI)

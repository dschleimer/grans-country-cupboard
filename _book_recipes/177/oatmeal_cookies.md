# Oatmeal Cookies

## Ingredients

| Ingredient  | Amount | Notes |
| ----------- | ------ | ----- |
| Shortening  | ¼ Cup  | |
| Sugar       | ½ Cup  | |
| Eggs        | 1      | |
| Molasses    | ⅔ Cup  | |
| Flour       | ¾ Cup  | |
| Baking Soda | ½ tsp  | Dissolved in a little warm water |
| Salt        | ½ tsp  | |
| Cinnamon    | ½ tsp  | |
| Nutmeg      | ½ tsp  | |
| Oatmeal     | 1 Cup  | |
| Raisins     | ½ Cup  | |

## Method

1. Cream shortening and sugar together
1. Add egg and molasses
1. Add flour, baking soda dissolved in a little warm water, salt, cinnamon, and nutmeg
1. Stir in oatmeal and raisins
1. Mix together with hands
1. Put small balls of mixture on a baking sheet and flatten
1. Bake at 400°F for 8–10 minutes

# "Mom's" Chocolate Layer Cake

## Ingredients

| Ingredient              | Amount   | Notes |
| ----------------------- | -------- | ----- |
| Melted Chocolate        | 4 blocks | |
| Butter                  | ¼ lb     | |
| Boiling Water           | 1 Cup    | |
| Sugar                   | 1 Cup    | |
| Sifted Flour            | 2 Cups   | |
| Baking Soda             | 2 tsp    | Dissolved in sour milk |
| Sour Milk               | ½ Cup    | May substitute Buttermilk |
| Buttermilk              | ½ Cup    | May substitute for Sour Milk |
| Salt                    | ½ tsp    | |
| Vanilla                 | 1 tsp    | |
| Beaten Stiff Egg Whites | 2        | |
| Beaten Egg Yolks        | 2        | added last |

## Method

1. Melt the chocolate with the butter
1. Add boiling water
1. Add sugar and sifted flour
1. Dissolve baking soda in sour milk or buttermilk and add
1. Add salt and vanilla
1. Fold in stiffly beaten egg whites
1. Add beaten egg yolks last
1. Pour into 3 well-greased and floured layer pans
1. Bake at 325°F for 20–35 minutes
1. Use soft chocolate icing

# Mrs Murray's Chocolate Cake

## Ingredients

| Ingredient            | Amount    | Notes |
| --------------------- | --------- | ----- |
| Butter                | ¼ lb      | |
| Sugar                 | 2 Cups    | |
| Eggs                  | 2         | Slightly beaten |
| Chocolate             | 2 squares | Melted |
| Flour                 | 2½ Cups   | |
| Buttermilk            | ½ Cup     | |
| Baking Soda           | ½ tsp     | |
| Salt                  | ¼ tsp     | |
| Vanilla               | 1 tsp     | |

## Method

1. Cream butter and sugar together
1. Add slightly beaten eggs
1. Add melted chocolate
1. Add flour alternating with buttermilk mixed with baking soda
1. Add salt and vanilla
1. Bake in layer pans at 350°F for about 25 minutes
1. Frost with soft chocolate icing

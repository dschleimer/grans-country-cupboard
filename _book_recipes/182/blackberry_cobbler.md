# Blackberry Cobbler

## Ingredients

| Ingredient    | Amount          | Notes |
| ------------- | --------------- | ----- |
| Blackberries  | 2½ cups         | |
| Lemon         | ½               | juiced |
| Butter        | 3 Tblsp         | |
| Salt          | ¼ tsp           | |
| Sugar         | ¾ cup + 1 cup   | |
| Flour         | 1 cup + 2 Tblsp | |
| Baking powder | 1 tsp           | |
| Milk          | ½ cup           | |
| Boiling Water | 1 cup           | |

## Method
1. Preheat oven to 350°F.
2. Grease 8" x 12" x 2" baking dish.
3. Put blackberries in baking dish.
4. Sprinkle with lemon juice.
5. Cream butter, salt, and ¾ cup sugar.
6. Sift 1 cup flour with baking powder.
7. Add flour alternately with milk to creamed mix.
8. Beat until firm, about 3 min. at high speed.
9. Spread dough evenly over berries.
10. Sprinkle with 1 cup sugar and 2 Tblsp flour.
11. Pour boiling water on top of sugar and flour.
12. Bake for one hour.

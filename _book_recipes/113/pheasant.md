# Pheasant

## Ingredients

| Ingredient    | Amount | Notes |
| ------------- | ------ | ----- |
| Pheasant      |        | |
| Flour         |        | |
| Butter        | ½ cup  | |
| Onions        | 2      | Chopped |
| White Wine    | 2 cups | Dinner Wine |
| Salt          |        | |
| Pepper        |        | |
| Garlic Powder |        | |
| Cloves        | ¼ tsp  | |
| Cream         | 1 cup  | |

## Method

1. Chop onion
1. Wash and quarter bird
1. Flour bird
1. Add bird and onions to butter
1. Fry until bird is brown
1. Add wine, salt, pepper, garlic powder, and cloves
1. Simmer covered about 1 hour or until tender
1. Remove bird from pan
1. Add cream
1. Cook, stirring constantly, until slightly thickened
1. Serve gravy over pheasant

## Notes From Gran

* Serve pheasant and gravy on rice if desired

# Venison Steak or Chops

## Ingredients

| Ingredient           | Amount | Notes |
| -------------------- | ------ | ----- |
| Venison              |        | |
| Red Wine             |        | Dinner Wine |
| Italian Bread Crumbs |        | |
| Butter               |        | |

## Method

1. Debone venison
1. Pound meat
1. Marinate for several hours in wine
1. Coat with bread crumbs
1. Cover and fry in butter until tender

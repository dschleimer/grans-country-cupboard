# Banana Nut Bread

## Ingredients

| Ingredient        | Amount  | Notes |
| ----------------- | ------- | ----- |
| Butter            | ¾ cup   | |
| Sugar             | 1½ cups | |
| Mashed Bananas    | 3       | |
| Beaten Light Eggs | 2       | |
| Vanilla           | 1 tsp   | |
| Sifted Flour      | 2 cups  | |
| Baking Soda       | 1 tsp   | |
| Salt              | ¾ tsp   | |
| Sour Cream        | 1 cup   | |
| Chopped Pecans    | ¾ cup   | May substitute pecan meal |

## Method

1. Preheat oven to 325 °F
1. Cream together butter and sugar
1. Mash bananas
1. Beat eggs until light and fluffy
1. Blend bananas, eggs, and vanilla into butter-sugar mix
1. Add flour, baking soda, and salt
1. Chop pecans if using nuts rather than meal
1. Add pecans and sour cream alternating
1. Grease bread pan well and flour
1. Pour batter into pan
1. Bake for 1 hour or more until done


## Notes From Gran

* You may double the ingredient quantities and bake in 3 pans
* Excellent for freezing if wrapped in foil

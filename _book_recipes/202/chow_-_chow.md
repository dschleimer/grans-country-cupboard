# Chow - Chow

## Ingredients

| Ingredient     | Amount | Notes |
| -------------- | ------ | ----- |
| Large Onions   | 3      | Coarsely ground |
| Green Tomatoes | 5      | Coarsely ground |
| Peppers        | 6      | Coarsely ground |
| Green Beans    | 2 Cups | Cut in 1" pieces |
| Cauliflower    | 2 Cups | Small buds |
| Lima Beans     | 2 Cups | |
| Pickling Salt  | ¾ Cup  | |
| Sugar          | 3 Cups | |
| Mustard Seed   | 1 Tbsp | |
| Celery Seed    | ½ tsp  | |
| Turmeric       | ¾ tsp  | |
| Vinegar        | 2 Cups | |
| Water          | 1 Cup  | |

## Method

1. Combine first 6 ingredients — sprinkle with salt and let stand overnight, then drain
2. Combine sugar, mustard seed, celery seed, turmeric, vinegar, and water over vegetables
3. Bring mixture to boiling point — boil gently 5 minutes
4. Fill hot jars to ½" of top and adjust lids
5. Process in boiling bath 5 minutes — start timing when water returns to boil
6. Makes 13 half pints

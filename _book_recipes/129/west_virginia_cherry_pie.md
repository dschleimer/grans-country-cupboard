# West Virginia Cherry Pie

## Ingredients

| Ingredient           | Amount    | Notes |
| -------------------- | --------- | ----- |
| Drained Red Cherries | 3½–4 Cups | |
| Sugar                | 1¾ Cups   | |
| Quick Tapioca        | 3 Tbsp    | |
| Salt                 | ⅛ tsp     | |
| Almond Extract       | ¼ tsp     | |
| Lemon Juice          | ½ Tbsp    | |
| Butter               | 1 Tbsp    | |
| Pie Crust            |           | For 9-inch pie |

## Method

1. Mix and pour into a 9-inch pie crust
1. Dot with butter
1. Cover with top crust, slash vents, and tuck top crust into bottom crust
1. Flute and fold around edges
1. Bake at 425°F for 30 minutes
1. Remove foil from edges
1. Bake 10 minutes longer
1. Allow to cool — the filling will increase in thickness as it cools
1. Let the pie reach room temperature before cutting for best results

## Modern Notes

* Quick tapioca acts as the thickener instead of cornstarch or flour — it produces a clearer, glossier filling
* The foil on the edges prevents over-browning during the initial bake — a common technique for fruit pies

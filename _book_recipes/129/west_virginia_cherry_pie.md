# West Virginia Cherry Pie

## Ingredients

| Ingredient           | Amount    | Notes |
| -------------------- | --------- | ----- |
| Drained Red Cherries | 3½–4 Cups | |
| Sugar                | 1¾ Cups   | |
| Quick Tapioca        | 3 Tbsp    | |
| Salt                 | ⅛ tsp     | |
| Almond Extract       | ¼ tsp     | |
| Lemon Juice          | ½ tsp     | |
| Molasses             | 1 Tbsp | Optional |
| Butter               | 1 Tbsp    | |
| Pie Crust            | 2         | See the [Pie Crust](/book_recipes/127/pie_crust.html) recipe |

## Method

1. Preheat oven to 425°F
1. Line bottom of 9-inch pie dish with 1 crust
1. Mix all ingredients other than butter
1. Pour into a pie crust
1. Dot with butter
1. Cover with other crust, seal top and bottom crust together, and slash vents in top crust
1. Flute around edges of crusts and cover edge with aluminum foil
1. Bake for 30 minutes
1. Remove foil from edges
1. Bake 10 minutes longer

# Grand-Dad Marter's Applejack

## Ingredients

| Ingredient | Amount | Notes |
| ---------- | ------ | ----- |
| Teaberries |        | Fresh |
| Applejack  |        | New Jersey Applejack (apple brandy) |

## Method

1. About ½ inch fresh teaberries in bottom of decanter
1. Fill with Applejack

## Notes From Gran
* Grand Dad Marter always kept this on his sideboard

## Modern Notes
* [Teaberries](https://en.wikipedia.org/wiki/Gaultheria_procumbens) appear to be a Berry native to parts of the East Coast.  It apparently tastes similar to mint.  I'd kind like to try some.  -- David S

# Wyoming Ice Box Cookies

## Ingredients

| Ingredient    | Amount | Notes |
| ------------- | ------ | ----- |
| White Sugar   | 2 Cups | |
| Brown Sugar   | 2 Cups | |
| Shortening    | 2 Cups | |
| Quick Oatmeal | 2 Cups | |
| Flour         | 6 Cups | |
| Eggs          | 4      | Large |
| Salt          | 1 tsp  | |
| Baking Soda   | 1 tsp  | |
| Chopped Nuts  | 2 Cups | |
| Vanilla       | 2 tsp  | |

## Method

1. Mix all ingredients well and form into a roll
1. Refrigerate several hours or overnight
1. Slice thin
1. Bake on a cookie sheet at 400°F for 12 minutes

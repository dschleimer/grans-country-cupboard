# Gingerbread

## Ingredients

| Ingredient  | Amount  | Notes |
| ----------- | ------- | ----- |
| Sugar       | ½ Cup   | |
| Butter      | ½ Cup   | |
| Eggs        | 3       | |
| Molasses    | 1 Cup   | |
| Flour       | 2½ Cups | Sifted |
| Baking Soda | 1 tsp   | Dissolved in a little warm water |
| Cinnamon    | 1 tsp   | |
| Ginger      | ⅛ tsp   | |
| Cloves      | ¼ tsp   | |
| Salt        | ½ tsp   | |
| Nutmeg      |         | Dash |
| Brandy      | ½ Cup   | |
| Hot Water   | ⅔ Cup   | Add last |

## Method

1. Cream sugar and butter together
1. Add eggs and beat until light
1. Add molasses
1. Sift flour and add
1. Dissolve baking soda in a little warm water and add
1. Add cinnamon, ginger, cloves, salt, and nutmeg
1. Stir in brandy
1. Add hot water last and beat smooth
1. Pour into a large greased and floured tube pan (or 2 smaller pans)
1. Bake at 350°F for 35–50 minutes

## Notes From Gran

* Batter rises very high

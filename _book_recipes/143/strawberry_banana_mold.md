# Strawberry Banana Mold

## Ingredients

| Ingredient              | Amount      | Notes |
| ----------------------- | ----------- | ----- |
| Strawberry-Banana Jello | 2 pkgs      | |
| Boiling Water           | 2 Cups      | |
| Frozen Strawberries     | 2 pkgs      | |
| Crushed Pineapple       | 1 large can | Drained |
| Chopped Nuts            | ½ Cup       | |
| Bananas                 | 2           | Sliced |
| Sour Cream              | 1 pint      | |
| Cream Cheese            | 3 oz        | |

## Method

1. Dissolve the Jello in 2 cups boiling water
1. Add frozen strawberries and stir until berries are thawed
1. Add drained crushed pineapple, chopped nuts, and sliced bananas
1. Pour half the mixture into a large bowl and refrigerate until set
1. Mix sour cream with cream cheese and spread on top of the set layer
1. Refrigerate until the sour cream layer is set
1. Add the other half of the Jello mixture on top
1. Refrigerate until fully set

## Modern Notes

* This is a three-layer Jello mold — fruit gelatin, sour cream/cream cheese, then more fruit gelatin
* Strawberry-banana Jello was a popular flavor in the 1970s — if unavailable, use strawberry Jello and add an extra banana

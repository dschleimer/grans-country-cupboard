# Paté de Foie Grásse

## Ingredients

| Ingredient | Amount | Notes |
| ---------- | ------ | ----- |
| Pig Liver  |        | From a 20-25 lb pig |
| Onions     |        | |
| Garlic     | little | |
| Eggs       |        | hard boiled |
| Seasoning  |        | |
| Crackers   |        | for serving |

## Method

1. Grind together all ingredients except crackers
1. Chill
1. serve pate on crackers

# Strawberry Fluff

## Ingredients

| Ingredient          | Amount | Notes |
| ------------------- | ------ | ----- |
| Egg Whites          | 2      | |
| Gran. Sugar         | ½ Cup  | |
| Frozen Strawberries | 1 pkg  | |
| Whipped Cream       | ½ Cup  | |
| Lemon Juice         |        | A few drops |

## Method

1. Beat egg whites slightly
1. Add a few drops of lemon juice, then gradually add sugar and strawberries alternately
1. Beat until the mixture expands to fill a quart bowl and is very stiff — this takes a while
1. Fold in whipped cream
1. Pile into parfait glasses and chill thoroughly
1. Garnish with a ripe strawberry and serve

# Italian Cheese Cake

## Ingredients

| Ingredient   | Amount | Notes |
| ------------ | ------ | ----- |
| Cream Cheese | 2 lb   | Cream together with ricotta |
| Ricotta      | 1½ lb  | |
| Sugar        | ¾ Cup  | |
| Eggs         | 4      | Add one at a time |
| Lemon Juice  | ½ tsp  | |
| Vanilla      | 1 Tbsp | |
| Cornstarch   | 3 Tbsp | |
| Flour        | 3 Tbsp | |
| Butter       | ¼ lb   | |
| Sour Cream   | 1 pint | |

## Method

1. Cream the cream cheese and ricotta together until smooth
1. Add the sugar and mix well
1. Add eggs one at a time, beating after each addition
1. Add lemon juice and vanilla in the order given
1. Add cornstarch and flour and mix
1. Add melted butter and sour cream
1. Pour into a greased 9-inch springform pan
1. Bake at 325°F until set
1. Turn off the oven and let the cake remain inside until cool

## Modern Notes

* Leaving the cheesecake in the turned-off oven to cool gradually helps prevent cracking
* This is a classic Italian-American style cheesecake — the combination of ricotta and cream cheese gives it a lighter texture than an all-cream-cheese version

# Pea Soup

## Ingredients

| Ingredient | Amount         | Notes |
| ---------- | -------------- | ----- |
| Split Peas | 2 lbs          | |
| Water      | 4 quarts       | |
| Ham hocks  | 2              | Skinned - Fat-trimmed - May substitute meaty ham bone |
| Onion      | 1 large        | Halved and Sliced |
| Garlic     | 2 large cloves | Smashed |
| Parsley    |                | |
| Ginger     | ¼ tsp          | |
| Marjoram   | 1 Tbsp         | |
| Bay Leaves | 2              | |
| Salt       | To Taste       | |
| Pepper     | To Taste       | |
| Brandy     | To Taste       | At serving time |

## Method

1. Boil splti pees in 4 quarts water for 5 minutes
1. Soak for 2 hours with lid on
1. Skin and trim Ham hocks if needed
1. Halve and slice onion
1. Smash garlic
1. Add all ingredients except Brandy
1. Simmer about 7 hours
1. Strain through coarse sieve
1. Remove bones and gristle
1. Puree rtemaining solids and add to soup
1. Add brandy to taste before serving

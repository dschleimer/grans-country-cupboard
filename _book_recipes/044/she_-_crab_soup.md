# She - Crab Soup

## Ingredients

| Ingredient           | Amount   | Notes |
| -------------------- | -------- | ----- |
| Onions               | ¼ cup    | Sliced |
| She-Crab Meat        | 2 cups   | with eggs |
| Butter               | 2 Tbsp   | |
| Flour                | 2 Tbsp   | |
| Milk                 | 4 cups   | |
| Cream                | 1 cup    | |
| Corn                 | 1 cup    | Cooked |
| Worcestershire Sauce | 1 tsp    | |
| Salt                 | To Taste | |
| Pepper               | To Taste | |
| Sherry               | 4 Tbsp   | At serving time |

## Method

1. Cook corn if needed
1. Slice onions
1. Simmer onions in butter until tender
1. Add crab meat with crab eggs
1. Heat thoroughly
1. Stir in flour, milk, and cream
1. Cook until thick
1. Add corn, Worcestershire Sauce, and seasonings
1. Add sherry just before serving

# Calico Salad

## Ingredients

| Ingredient               | Amount | Notes |
| ------------------------ | ------ | ----- |
| Drained Green Beans      | 1 lb   | recipe calls for a 1 lb can |
| Drained Wax Beans        | 1 lb   | recipe calls for a 1 lb can |
| Drained Red Kidney Beans | 1 lb   | recipe calls for a 1 lb can |
| Chopped Green Pepper     | ½ cup  | |
| Chopped Onion            | 2 Tbsp | |
| Sugar                    | ¼ cup  | |
| Vinegar                  | ⅔ cup  | |
| Salad Oil                | ⅓ cup  | |
| Salt                     | 1½ tsp | |
| Pepper                   | ½ tsp  | Recipe specifies Black pepper |

## Method

1. Add sugar, vinegar, salad oil, salt, and pepper to a jar
1.  Close jar and shake to combine into dressing
1. Pour dressing over beans in a large bowl
1. Mix and cover
1. Chill several hours or overnight before serving

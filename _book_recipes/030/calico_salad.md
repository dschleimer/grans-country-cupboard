# Calico Salad

## Ingredients

| Ingredient       | Amount | Notes |
| ---------------- | ------ | ----- |
| Green Beans      | 1 lb   | Drained - recipe calls for a 1 lb can |
| Wax Beans        | 1 lb   | Drained - recipe calls for a 1 lb can |
| Red Kidney Beans | 1 lb   | Drained - recipe calls for a 1 lb can |
| Green Pepper     | ½ cup  | Chopped |
| Onion            | 2 Tbsp | Chopped |
| Sugar            | ¼ cup  | |
| Vinegar          | ⅔ cup  | |
| Salad Oil        | ⅓ cup  | |
| Salt             | 1½ tsp | |
| Pepper           | ½ tsp  | Recipe specifies Black pepper |

## Method

1. Add sugar, vinegar, salad oil, salt, and pepper to a jar
1.  Close jar and shake to combine into dressing
1. Pour dressing over beans in a large bowl
1. Mix and cover
1. Chill several hours or overnight before serving

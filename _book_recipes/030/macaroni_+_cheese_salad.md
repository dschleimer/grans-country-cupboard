# Macaroni + Cheese Salad

## Ingredients

| Ingredient     | Amount     | Notes |
| -------------- | ---------- | ----- |
| Elbow Macaroni | 1 lb       | |
| Sharp Cheddar  | 8 oz       | Shredded |
| Green Peppers  | 1 cup      | Chopped |
| Celery         | 1 cup      | Chopped |
| Onion          | 2 tsp      | Grated |
| Salt           | 2 tsp      | |
| Pepper         | To Taste   | |
| Tabasco Sauce  | Dash       | |
| Relish         | 2 Tbsp     | |
| Mayonnaise     | 1 1/2 cups | |
| Mustard        | 1 1/2 tsp  | |
| Vinegar        | 2 tsp      | Sweet Pickle Juice |

## Method
1. Cook macaroni as directed on box
1. Shred cheese if in block
1. Chop peppers and celery
1. Grate Onion
1. Combine everything

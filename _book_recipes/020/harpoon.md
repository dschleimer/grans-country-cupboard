# Harpoon

## Ingredients

| Ingredient      | Amount     | Notes |
| --------------- | ---------- | ----- |
| Rum             | 2 Jiggers  | |
| Sweet Vermouth  | 1 Jigger   | |
| Creme de Menthe | 2/3 Jigger | White |
| Creme de Cocoa  | 2/3 Jigger | |
| Lime            | 1/2        | Juiced - Use Lime OR Lemon juice not both |
| Lemon           | 1/2        | Juiced - Use Lime OR Lemon juice not both |
| Ice             | 4 cubes    | Cracked |

## Method

1. Juice 1/2 lime or 1/2 lemon
1. Combine all ingredients in blender
1. Mix 2-3 seconds

## Notes From Gran
* Makes 2 servings

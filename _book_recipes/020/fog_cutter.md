# Fog Cutter

## Ingredients

| Ingredient   | Amount   | Notes |
| ------------ | -------- | ----- |
| Lemon Juice  | 1 oz     | |
| Orange Juice | 1 oz     | |
| Gin          | 1/2 oz   | |
| Brandy       | 1/2 oz   | |
| Light Rum    | 1 1/2 oz | |
| Orgeat       | 1/2 oz   | |
| Sherry       |          | Float |

## Method

1. Shake well
1. Serve in 14 oz glass over chopped ice
1. Float sherry on top

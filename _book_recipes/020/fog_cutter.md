# Fog Cutter

## Ingredients

| Ingredient   | Amount | Notes |
| ------------ | ------ | ----- |
| Lemon Juice  | 1 oz   | |
| Orange Juice | 1 oz   | |
| Gin          | ½ oz   | |
| Brandy       | ½ oz   | |
| Light Rum    | 1½ oz  | |
| Orgeat       | ½ oz   | |
| Sherry       |        | Float |

## Method

1. Shake well
1. Serve in 14 oz glass over chopped ice
1. Float sherry on top

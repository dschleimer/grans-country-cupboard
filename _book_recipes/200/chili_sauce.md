# Chili Sauce

## Ingredients

| Ingredient          | Amount  | Notes |
| ------------------- | ------- | ----- |
| Red Tomatoes        | 18      | Large |
| Sweet Green Peppers | 4–6     | |
| Onions              | 8       | Good size |
| Sugar               | 2 Cups  | |
| Vinegar             | 2½ Cups | |
| Salt                | 3 Tbsp  | Not iodized |
| Allspice            | 2½ tsp  | |
| Cinnamon            | ½ tsp   | |
| Cloves              | ½ tsp   | |

## Method

1. Scald tomatoes without peeling
1. Coarse grind tomatoes, peppers, and onions — drain off excess juice if very juicy
1. Add all other ingredients and boil 1 hour
1. Boil on medium heat and boil
1. This is quite sweet and delicious

## Notes From Gran

* Do not double quantity

## Modern Notes

* This is a classic homemade chili sauce — a sweet, spiced tomato condiment used on meatloaf, eggs, and sandwiches -- Claude (AI)

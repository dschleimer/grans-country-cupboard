# Spiced Corn Beef

## Ingredients

| Ingredient          | Amount      | Notes |
| ------------------- | ----------- | ----- |
| Corned Beef Brisket | About 5 lbs | |
| Vinegar             | 1/4 cup     | |
| Water               | 1/2 cup     | |
| Molasses            | 2 Tbsp      | |
| Bay Leaves          | 2           | |
| Peppercorns         | 1 tsp       | |
| Celery Seed         | 1 tsp       | |
| Cloves              | 6           | Whole Cloves |
| Ginger              | 1/4 tsp     | |
| Dry Mustard         | 1/4 tsp     | |

## Method

1. Place brisket in shallow pan
1. Mix together all remaining ingredients into a marinade
1. Pour over brisket
1. Cover
1. Refrigerate overnight, turning once
1. Place beef with marinade into deep pot
1. Add enough water to cover meat
1. Bring to a boil
1. Reduce heat
1. Cover
1. Simmer for 4 hour until meat is tender

## Notes From Gran

* Serve with Irish Colcannon (potato and cabbage dish)
* 2 servings per lb

# Eunie's Oven Beef Stew

## Ingredients

| Ingredient             | Amount    | Notes |
| ---------------------- | --------- | ----- |
| Stew Beef              | 1 1/2 lbs | |
| Stew Vegetables        | 2 bags    | |
| Cream of Mushroom Soup | 1 can     | |
| Salt                   |           | |
| Pepper                 |           | |
| Worcestershire Sauce   | Dash      | |

## Method

1. Preheat over to 350F
1. Cut stew beef into bite-sized pieces
1. Add beef and vegetables to baking dish or oven-safe pot
1. Add soup
1. Fill soup can half full of water, rinsing can, and add
1. Add salt, pepper, and Worcestershire Sauce
1. Cover with foil
1. Bake 3 to 4 hours, adding more water if needed

# Jiffy Tomato Aspic

## Ingredients

| Ingredient   | Amount   | Notes |
| ------------ | -------- | ----- |
| Tomato Juice | 14 oz    | Recipe specifies a 14 oz can |
| Lemon Jello  | 1 pkg    | |
| Vinegar      | 1 Tbsp   | |
| Celery       | 1 cup    | Minced |
| Green Pepper | 2 Tbsp   | Minced |
| Onion        | 1 Tbsp   | Grated |
| Salt         | 1/2 Tbsp | |
| Mayonnaise   |          | For Serving |

## Method

1. Mince Celery and Green Pepper
1. Grate Onion
1. Boil Tomato Juice
1. Dissolve Jello in boiling Tomato Juice
1. Stir in remaining ingredients except for Mayonaisse 
1. Chill

## Notes
* Serve with Mayonnaise

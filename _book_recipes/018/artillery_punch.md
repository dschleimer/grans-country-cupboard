# Artillery Punch

## Ingredients

| Ingredient   | Amount  | Notes |
| ------------ | ------- | ----- |
| Whiskey      | 1 fifth | |
| Vodka        | 1 fifth | |
| Claret Wine  | 1 fifth | |
| Ginger Ale   | 1 quart | |
| Club Soda    | 1 quart | |
| Lemons       | 6       | See modern notes below |
| Sugar        | 1 cup   | See modern notes below |
| Oranges      |         | Sliced |
| Cherries     |         | |
| Cherry Juice | "some"  | See modern notes below |

## Method

1. Slice oranges
1. Juice lemons if using fresh
1. Combine sugar and liquid ingredients
1. Pour over large cake of ice into punch bowl
1. Add orange slices and Cherries to punch bowl

## Notes
* Ceterers allow 3 or 4 punch cups per person

## Modern Notes
* A fifth of liquor refers to a 750 ml bottle, i.e. the most common size of alcohol bottle in 2025.
* The original recipe calls from "sugar for lemonade for 6 lemons".  Exact ratios of sugar to lemon juice in lemonade recipes vary, but not by all that much.  All of the recipes I checked called for around 1 cup of sugar.  --David S
* The original recipe called for "cherries + some juice".  I interpret the "some juice" as Cherry juice to your flavor/color preference. --David S

# Yellow Squash Casserole

## Ingredients

| Ingredient                | Amount   | Notes |
| ------------------------- | -------- | ----- |
| Squash                    | 2 lbs    | |
| Beaten Eggs               | 2        | |
| Mayonnaise                | 1 cup    | Blue Ribbon Mayonnaise |
| Onion Chopped Fine        | 1        | |
| Green Pepper Chopped Fine | ¼ cup    | |
| Parmesan                  | 1 cup    | |
| Salt                      | To Taste | |
| Pepper                    | To Taste | |
| Butter                    |          | |
| Seasoned Bread Crumbs     |          | |

## Method

1. Preheat oven to 350 °F
1. Butter baking dish
1. Wash squash
1. Cut into chunks
1. Cook tender
1. Drain
1. Chop Onion and Green Pepper fine
1. Beat eggs
1. Add onion, Green Pepper, Mayonnaise, and Parmesan
1. Add Salt and Pepper to taste
1. Mix well
1. Put into buttered baking dish
1. Add seasoned bread crumbs
1. Dot with Butter
1. Bake for 30 minutes

# Spanish Cream

## Ingredients

| Ingredient    | Amount     | Notes |
| ------------- | ---------- | ----- |
| Gelatin       | ½ envelope | |
| Milk          | 3 Cups     | |
| Eggs          | 3          | Separated |
| Sugar         | ½ Cup      | |
| Salt          | ¼ tsp      | |
| Vanilla       | 1 tsp      | |
| Whipped Cream |            | For serving |

## Method

1. Soak gelatin in ½ cup of the milk for 10 minutes
1. Scald the remaining milk
1. Beat egg yolks well and slowly pour the hot milk over them, stirring
1. Add sugar and salt, then return to the double boiler
1. Cook until the mixture coats a spoon
1. Remove from stove and add the soaked gelatin, stirring to dissolve
1. When partially cool, fold in stiffly beaten egg whites and vanilla
1. Turn into individual molds first dipped in cold water
1. Chill until set
1. Serve with whipped cream

## Notes From Gran

* Use more gelatin (1 Tbsp) if a firmer set is needed

## Modern Notes

* Spanish cream is a classic molded custard dessert — the egg whites create a light, two-toned effect when set, with a clear layer on top and creamy layer on the bottom -- Claude (AI)
* Dipping molds in cold water helps the custard release cleanly -- Claude (AI)

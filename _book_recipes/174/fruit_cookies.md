# Fruit Cookies

## Ingredients

| Ingredient  | Amount | Notes |
| ----------- | ------ | ----- |
| Butter      | 1 Cup  | |
| Sugar       | 1 Cup  | |
| Milk        | 1 Cup  | |
| Beaten Eggs | 2      | |
| Flour       | 2 Cups | |
| Baking Soda | ¼ tsp  | |
| Currants    | ¾ Cup  | |
| Raisins     | ¾ Cup  | |
| Rolled Oats | 2 Cups | |

## Method

1. Cream butter and sugar together
1. Add milk and beaten eggs
1. Add flour with baking soda
1. Stir in currants, raisins, and rolled oats
1. Mix well
1. Drop on an unbuttered pan
1. Bake at 325°F

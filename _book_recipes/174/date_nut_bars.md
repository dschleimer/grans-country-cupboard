# Date Nut Bars

## Ingredients

| Ingredient       | Amount | Notes |
| ---------------- | ------ | ----- |
| Melted Butter    | ¼ Cup  | |
| Sugar            | 1 Cup  | |
| Eggs             | 2      | Beaten lightly |
| Flour            | ¾ Cup  | |
| Baking Powder    | ¼ tsp  | |
| Dates            | 1 Cup  | Cut up |
| Chopped Walnuts  | 1 Cup  | |
| Granulated Sugar |        | For rolling |

## Method

1. Combine melted butter and sugar
1. Add lightly beaten eggs
1. Add flour and baking powder, mix well
1. Stir in dates and chopped walnuts
1. Bake at 350°F for 25–30 minutes in an 8-inch square pan
1. Cut into squares while warm
1. Roll in granulated sugar

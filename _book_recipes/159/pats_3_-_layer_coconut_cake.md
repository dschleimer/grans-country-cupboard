# Pat's 3-Layer Coconut Cake

## Ingredients

| Ingredient              | Amount  | Notes |
| ----------------------- | ------- | ----- |
| Butter                  | 1 Cup   | |
| Sugar                   | 3 Cups  | |
| Flour                   | 3½ Cups | |
| Baking Powder           | 3½ tsp  | |
| Salt                    | ½ tsp   | |
| Milk                    | 1 Cup   | |
| Beaten Stiff Egg Whites | 6       | |
| Vanilla Extract         | ½ tsp   | |
| Almond Extract          | ½ tsp   | |
| Coconut                 | 2 Cups  | Optional |

## Method

1. Cream butter and sugar well
1. Combine flour, baking powder, and salt
1. Add dry ingredients alternately with milk
1. Fold in stiffly beaten egg whites
1. Stir in vanilla extract, almond extract, and coconut
1. Pour into 3 greased and floured 9-inch pans
1. Bake at 375°F for 30–35 minutes
1. Cool completely
1. Frost with Pat's White Frosting and sprinkle coconut between layers, on top, and on sides

## Notes From Gran

* If using fresh coconut, poke a nail punch through the eye to drain the coconut milk — drizzle over each layer

## Modern Notes

* This is a classic Southern coconut layer cake — all egg whites (no yolks) keep the cake snowy white -- Claude (AI)

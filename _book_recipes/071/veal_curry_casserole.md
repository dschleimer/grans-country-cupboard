# Veal Curry Casserole

## Ingredients

| Ingredient             | Amount      | Notes |
| ---------------------- | ----------- | ----- |
| Veal                   | 3 lbs       | Cubed |
| Onion                  | 1 cup       | Chopped |
| Cream of Mushroom Soup | 1 can       | |
| Milk                   | 1¼ cups     | |
| Curry                  | 1 or 2 Tbsp | |
| Pepper                 | Dash        | |
| Thyme                  | Pinch       | |
| Marjoram               | Pinch       | |
| Brazil Nuts            | 1 cup       | May use Almonds instead |
| Almonds                | 1 cup       | May use Brazil nuts instead |
| Margerine              |             | |

## Method

1. Preheat oven to 350 °F
1. Cube Veal if not already
1. Chop Onion
1. Sauté Veal in Margerine
1. Add chopped onions
1. Brown
1. Place Veal and Onion in Casserole, preserving fat in skillet
1. Pour soup in skillet
1. Stir in Milk, Curry, Pepper, Thyme, and Marjoram
1. Mix and heat
1. Add nuts
1. Pour over meat in casserole
1. Bake 45 minutes

# Green Beans Superb

## Ingredients

| Ingredient   | Amount   | Notes |
| ------------ | -------- | ----- |
| Onion        | 2 Tbsp   | Chopped |
| Green Pepper | 1 Tbsp   | Chopped |
| Butter       | 3 Tbsp   | |
| Flour        | 2 Tbsp   | |
| Salt         | 1 tsp    | |
| Paprika      | 1/2 tsp  | |
| Pepper       | To Taste | |
| Milk         | 1 cup    | |
| Bean Liquor  | 1/2 cup  | |
| Pimento      | 1        | Chopped |
| Cheese       | 1/4 cup  | Grated |
| Green Beans  | 2 cups   | Cooked and still Hot |

## Method

1. Cook beans
1. While beans are cooking, chop Onions and Green Peppers
1. Chop Pimento
1. Grate Cheese
1. When beans are ready, sautee Onions and Green Peppers in butter
1. Add beans and remaining ingredients to Onions and Green Peppers
1. Stir until Cheese melts

## Notes
* Serves 6

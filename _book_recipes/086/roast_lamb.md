# Roast Lamb

## Ingredients

| Ingredient  | Amount   | Notes |
| ----------- | -------- | ----- |
| Leg of Lamb | 6-8 lbs  | Boned and Rolled |
| Salt        |          | |
| Pepper      |          | |
| Rosemary    |          | |
| Garlic      |          | |
| Onion       | 2 slices | On top |

## Method

1. Debone and roll leg of lamb, if your butcher has not done so
1. Preheat oven to 325 °F
1. Season with salt, pepper, rosemary, and garlic
1. Slice onion and lay on top of lamb
1. Cover lamb
1. Roast about 3 hours or until meat is very tender
1. Add water when needed

## Notes From Gran

* Serve with gravy
* Good cold

# Tomato Soup

## Ingredients

| Ingredient  | Amount | Notes |
| ----------- | ------ | ----- |
| Tomatoes    | 8      | |
| Water       | 1 pint | |
| Salt        | 1 tsp  | |
| Sugar       | 1 Tbsp | |
| Cloves      | 5      | whole |
| Peppercorns | ½ tsp  | |
| Parsley     | 1 Tbsp | |
| Onion       | 1 Tbsp | Grated |
| Flour       | 1 Tbsp | |
| Butter      | 1 Tbsp | |

## Method

1. Peel tomatoes
1. Stew for 20 minutes
1. Add remaining ingredients

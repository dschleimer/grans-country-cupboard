# Crumb Cake

## Ingredients

| Ingredient  | Amount | Notes |
| ----------- | ------ | ----- |
| Flour       | 2 Cups | Mix and reserve ½ cup crumbs |
| Brown Sugar | 2 Cups | |
| Butter      | ½ Cup  | |
| Salt        | ½ tsp  | |
| Milk        | 1 Cup  | |
| Cinnamon    | 1 tsp  | |
| Cloves      | ½ tsp  | |
| Nutmeg      | ½ tsp  | |
| Vanilla     | 1 tsp  | |
| Baking Soda | 1 tsp  | |

## Method

1. Mix flour, brown sugar, and butter together until crumbly
1. Reserve ½ cup of the crumb mixture for topping
1. To the remaining mixture add salt, milk, cinnamon, cloves, nutmeg, vanilla, and baking soda
1. Beat 1 minute and pour into a well-greased and floured cake pan
1. Sprinkle the reserved crumbs on top
1. Bake at 325°F for 30 minutes and cut into squares

## Modern Notes

* This is a classic crumb cake where the same butter-sugar-flour base serves as both the cake batter and the crumb topping
* The spices give it a warm, old-fashioned flavor similar to gingerbread

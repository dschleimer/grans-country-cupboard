# Vanilla Icing

## Ingredients

| Ingredient          | Amount | Notes |
| ------------------- | ------ | ----- |
| Confectioners Sugar | 1 Cup  | |
| Egg Yolks           | 2      | |
| Butter              | 1 Tbsp | |
| Vanilla             | 1 tsp  | |
| Cream               |        | To desired consistency |

## Method

1. Combine confectioners sugar, egg yolks, and butter
1. Add vanilla
1. Add cream to give the desired consistency
1. Spread on cake

# Cocoa Filling for 3 - Layer Cake

## Ingredients

| Ingredient          | Amount  | Notes |
| ------------------- | ------- | ----- |
| Confectioners Sugar | 1½ Cups | |
| Butter              | 1½ Tbsp | |
| Cocoa               | 8 tsp   | |
| Vanilla             | 1 tsp   | |
| Cream               | 2 tsp   | |
| Warm Milk           | 2 Tbsp  | |

## Method

1. Combine confectioners sugar, butter, cocoa, vanilla, and cream
1. Add warm milk and mix until smooth and spreadable
1. Spread between the layers of a 3-layer cake
